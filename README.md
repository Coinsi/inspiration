# Inspiration —— 影视/动漫 AIGC 资产管理与生产平台

以"资产管理 + 配置管理"思想为内核,贯通 **小说 → 大纲 → 剧本 → 场次 → 镜头 → 资产 → 生成 → 成片** 全流程的 AIGC 影视/动漫生产平台。

## 仓库结构

```
inspiration/
├─ docs/         # 文档体系(需求→概要→详细设计→开发计划)见 docs/README.md
├─ backend/      # FastAPI 模块化单体(见 backend/README.md)
├─ frontend/     # React + TS + Tailwind(见 frontend/README.md)
└─ deploy/       # docker-compose 一体化部署(单机自托管)
```

## 一键启动(推荐)

```bash
cd deploy
docker compose up --build
```

启动后:
- 前端:http://localhost:5173 (默认账号 **demo / demo1234**)
- 后端 API 文档:http://localhost:8000/docs
- MinIO 控制台:http://localhost:9001 (minioadmin / minioadmin)

`api` 容器启动时自动执行迁移(建全表)并写入种子数据。

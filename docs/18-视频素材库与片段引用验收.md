# 视频素材库与片段引用第三批验收

日期：2026-09-15。基线 `6f135d4`，分支 `codex/character-production-tools`。三批改动均未提交、未合并、未推送。

## 本批可用流程

1. 项目侧栏进入「视频素材」，导入 MP4、MOV、MKV、WebM。8 MiB 顺序分块上传，显示实际已完成字节数；暂停、关闭页面或刷新后，重新选择原文件即可续传。续传逐块核对已上传内容的 SHA-256，不只相信文件名、大小或首尾摘要。
2. 上传完成进入持久队列，后台探测视频、保留原片、制作 H.264/AAC 轻量预览和封面。预览不超过 1280×720，保持比例。状态区分待续传、等待处理、制作预览、可使用、失败、取消。失败可重试；进程中断后的 processing 任务可重新领取。
3. 预览中输入入点/出点，或将当前画面设为边界。选择目标镜头、用途、备注，保存 `素材版本 + 镜头 + 毫秒范围 + 用途`。镜头详情可以播放这段引用；上传新版本不会改变已有引用。
4. 删除前显示所有版本的引用和活动任务。仍有引用或上传/处理任务时，前后端均阻止移入回收站。可以解除指定引用后移入回收站，也可以恢复。并发创建引用与删除由同一素材记录锁串行处理。
5. 图片/角色/场景继续使用原有资产库。新视频库采用相同导航、明暗主题、加载/错误状态和窄屏布局。

本批参考影策的[项目素材](https://github.com/Coinsi/open-ai-canvas/blob/main/backend/internal/app/project_asset.go)和[删除依赖](https://github.com/Coinsi/open-ai-canvas/blob/main/backend/internal/app/resource_delete.go)分层思路；实现沿用本项目权限、审计、内容寻址存储和镜头模型。没有复制它的整套存储实现，也不声称已与其功能对齐。

## 数据与运行方式

- 新表：`library_media`、`media_version`、`media_usage`。迁移版本 `0006_media_library`。
- 原片/代理/封面通过稳定 Blob 哈希关联；本地文件存储与 S3 兼容对象存储复用同一接口。临时 URL 不作为素材身份。
- 上传暂存以服务器生成的 UUID 命名。服务端已提交的字节数是续传依据；写入 fsync，事务未提交留下的尾部在下一次写入前截断。
- 大文件入库使用流式哈希和文件复制；下载/视频播放使用 Range 和流式响应，释放数据库连接后再传输。既有图片、音频、生成视频读取路径保留权限检查。
- 队列使用 PostgreSQL 会话锁限制同一数据库同时一个编码任务。FFmpeg 使用两线程编码；正常停机发出取消信号，将任务重新排队。磁盘/编码失败显示失败状态，不虚报编码百分比。
- 配置：`LIBRARY_STAGING_DIR`（默认 `./_library_staging`）、`LIBRARY_MAX_UPLOAD_BYTES`（默认 10 GiB）、`LIBRARY_WORKER_ENABLED`（默认启用）。视频探测限制 6 小时。该数值是接收限制，不代表已经完成同等规模压力测试。
- 暂存目录需要持久磁盘。本批运行面向单主机；多主机部署必须共享暂存目录，或进一步改为对象存储分片直传与独立处理队列。磁盘容量、项目配额、后台清理仍需补齐。

## 迁移与预览隔离

发现初始迁移使用实时 ORM metadata 建表，导致新安装时提前建出后续迁移的表/列。已将 `0001_initial` 固定为该版本 DDL 快照，后续版本继续各自管理增量；用独立随机测试 schema 验证从零安装、0005→0006、回退0005、再次升级。

当前 5187 前端连接 8003 预览 API，使用独立 schema `inspiration_preview_ebdb_20260915`，复制了原环境的项目记录用于查看。原有 public schema 保持 `0005_setting`；原 8000 服务未执行新迁移。忽略的 worktree `backend/.env` 保存预览连接设置，不进入代码提交。原 Blob 对象按不可变内容共享，新测试项目和引用记录仅在隔离预览中创建。

其他环境启动本批代码前需正常执行 `alembic upgrade head`。不要把尚未升级的 main API 配给本批前端。

## 明确未包含

- 当前是**项目内视频素材库**，还没有跨项目共享库、全库分页/目录/标签和批量操作。搜索目前按素材名过滤。
- 没有视频内容索引、字幕抽取、人物识别、语义/图片检索；下一批从可追溯的片段、关键帧与文本证据开始，再做检索评测。
- 引用不会自动送给生成模型、加入时间线或导出裁剪文件。后续按供应商输入限制物化参考片段，并为导出建立任务保留关系。
- 毫秒范围是引用数据合同；浏览器 `timeupdate` 停播有事件粒度，不能当作逐帧剪辑/导出精度保证。
- 回收站不释放原片、预览或封面物理空间。彻底删除、跨项目依赖、存储回收、内容索引清理和正在导出/生成任务的保留租约仍待实现。
- 尚未对10 GiB、6小时、多用户大规模并发做压力验证，也未验证所有容器/编码组合。支持扩展名不保证每个视频都能解码，失败会明确显示。

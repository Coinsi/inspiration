## 1. 设计方向(为什么推倒重来)

现有 v1 是 **Linear 骨架 + Jellyfin 海报墙**,强调色为 violet/teal,观感"干净的 SaaS 后台"。
参考截图传递的是另一种气质——**"在控制室里指挥一部电影的生成"**:

- **深空感**:近黑微蓝底色 + 顶部柔和辉光 + 暗角,沉浸如放映厅。
- **琥珀金灯光**:主操作(生成影片/生成视频/升级)用暖金渐变 + 外发光,像聚光灯。
- **青蓝科技线**:工作流节点、骨骼绑定、轨迹曲线用青蓝,与金形成"暖/冷"双强调。
- **玻璃面板**:半透明卡片 + 细描边 + 弱阴影,多面板拼成"工作台仪表盘"。
- **工业排版**:时间码 / 分辨率 / fps / 编号一律等宽数字,强化"专业制片工具"感。

> 一句话:**v1 是"管理资产的后台",v2 是"生成电影的驾驶舱"。**

## 2. 设计令牌(Design Tokens)

两套 CSS 变量(HSL),`<html>` 上 `.dark` / `.light` 切换。完整值见原型 `ui-prototype-v2.html` `:root`。

### 2.1 深色(主)
| 角色 | HSL | 近似 | 用途 |
|---|---|---|---|
| `--bg` | `218 38% 5%` | `#070A12` | 全局底(配辉光渐变) |
| `--surface` | `220 32% 8%` | `#0E121C` | 顶栏/侧栏(半透明+模糊) |
| `--panel` | `219 30% 10%` | `#121826` | 面板底 |
| `--card` | `218 28% 13%` | `#171F2E` | 卡片 |
| `--elevated` | `217 26% 17%` | `#212A3B` | 输入/悬浮 |
| `--border` | `216 24% 19%` | `#262F40` | 描边 |
| `--fg` / `--muted` / `--faint` | `…94%` / `…62%` / `…44%` | | 三级文字 |
| **`--primary`(琥珀金)** | `38 78% 64%` | `#E9B96B` | 主强调/CTA/进度/Logo |
| `--primary-strong` | `34 72% 52%` | 渐变深端 | 按钮渐变/发光 |
| **`--accent`(青蓝)** | `188 64% 56%` | `#54C6D6` | 工作流/骨骼/次强调 |
| 语义 | success `158 58% 56%` · warning `38 92% 60%` · danger `2 80% 66%` · info `210 90% 68%` | | 状态/徽章 |

### 2.2 浅色(次)
保留金/青双强调但压暗以保证对比度(`--primary 34 76% 44%`、`--accent 190 70% 38%`);底 `220 30% 96%`、卡片纯白、描边 `220 18% 88%`、文字 `220 35% 14%`。顶部辉光改为暖白。

### 2.3 形与质
- **圆角**:面板 14px、卡片 10–11px、按钮/输入 8–9px、徽章/头像 full。
- **发光**:仅 `--primary` 元素带外发光(`box-shadow … hsl(--primary-glow)`),其余靠描边分层。
- **玻璃**:面板背景用半透明渐变 `--glass` + `backdrop-filter: blur`。
- **字体**:UI = Inter + `PingFang SC`/`Microsoft YaHei`;数字/编号/时间码 = `.mono`(JetBrains Mono,开 `tnum`)。
- **动效**:120–160ms;悬停 `translateY(-1px)` + 强调描边;无装饰动画。

```
┌────┬───────────────────────────────────────────────────────────┐

│ 📜 │ ┌脚本编辑──┐ ┌工作流(节点)┐ ┌角色一览────┐                  │
│ 🎭 │ │          │ │   ◆        │ │ ▢ 林夏 主角 │                  │
│ 🏙️ │ └──────────┘ └────────────┘ └────────────┘                  │
│ 🎬 │ ┌分镜时间轴───────────────────┐ ┌场景管理──┐                 │
│ 🗂️ │ │ □ □ ▣ □ □ □                │ │ ▣ ▣ ▣ ▣ │                 │
│ ✨ │ └────────────────────────────┘ └──────────┘                 │
│    │ ┌成片预览(播放器)─────────────┐ ┌成片信息──┐                 │
│ ⚙️ │ │  ▶ ━━━━━━━━━━ 00:12/01:20  │ │ 4K 24fps │                 │
│    │ └────────────────────────────┘ └用量 32%──┘                 │
└────┴───────────────────────────────────────────────────────────┘
 60px 图标栏          顶栏(品牌+状态+全局动作)        工作台 3 列响应栅格
```

- **左侧 60px 图标栏**(替换 v1 的 248px 文字侧栏):图标 + 微缩中文/英文标签,选中态金色指示条 + 辉光。空间留给富媒体主区。鼠标悬停出 tooltip;可选展开抽屉。
- **顶栏**:左品牌(Logo 金色发光胶囊 + 标题 + 副标),右侧依次:保存状态胶囊、**语言切换 🌐**、**主题切换 🌙/☀**、导出、**主 CTA「生成影片」**(金色发光)、头像。
- **工作台(首页)**:`grid` 三列多行,面板区域命名(script/flow/roster/timeline/scenes/preview/info),`@media` 下断点收成单列。
- 功能页(资产/镜头/成片…)沿用同一外壳,主区替换为各自内容(海报墙/Kanban/时间线)。

## 6. 双语与双主题实现

- **i18n**:沿用 `lib/i18n.tsx` 字典模式,**补全 v2 新增键**(面板标题/工作流节点/角色徽章/播放器/用量等,见原型 `DICT`)。建议把字典拆到 `lib/locales/{zh,en}.ts` 以便扩张。顶栏 🌐 切换,持久化 localStorage。
- **主题**:沿用 `lib/theme.tsx`,`.dark/.light` 切类;令牌全部走 CSS 变量,组件零硬编码颜色。新增"跟随系统"可选项(`prefers-color-scheme`)。顶栏 🌙/☀ 切换。
- **验证**:四象限(暗/亮 × 中/英)逐页过一遍对比度(WCAG AA)与不溢出(英文更长,按钮/标签留弹性)。

## 7. 技术落地

- **令牌**:重写 `src/index.css` 的 `:root/.dark/.light` 变量为 v2 值;`tailwind.config.js` 扩 `accent`、`primary-strong`、发光阴影。
- **外壳**:`AppShell.tsx` 改为 60px 图标栏 + 顶栏布局(现为 248px 文字侧栏);新增 `Topbar` 组件承载全局动作。
- **新组件**:`components/ui/` 增 `Panel / PrimaryButton / WorkflowGraph / CharacterCard / StoryboardTimeline / SceneCard / FilmPlayer / UsageMeter / MonoBadge`。
- **新首页**:`pages/Workbench.tsx`(工作台仪表盘),设为项目默认路由。
- **不改后端**:纯前端;数据接口与 `lib/api.ts` 不变,缺失字段(如工作流状态)用既有镜头/场景/资产数据拼装或 mock 占位。

# 工作台与导航首批改造验收

日期：2026-09-15。基线：`6f135d4`。本批只修改前端与文档，未提交、未合并、未推送。

## 用户可用的变化

- 项目入口：按名称/编号/描述搜索，按创建日期/名称排序；区分请求失败、没有项目和没有搜索结果；新建表单带明确标签、键盘提交与空白校验。
- 工作台：项目标题与真实资产封面、继续创作入口、五个制作阶段（故事/剧本/资产/分镜/剪辑）、镜头/资产预览、章节范围筛选、镜头准备情况、最近五项任务及项目用量。
- 制作阶段显示对应真实数量，不把“有时间线”当“已输出成片”；选定画面与通过审阅分别呈现。修正之前“成片播放暂不可用”的过期文案。
- 顶部显示所在项目和页面，侧栏与快速导航共用入口目录。快速导航支持 Ctrl/Cmd+K、关键词过滤、上下键/Enter、Escape与焦点恢复；包含原有入口以及回收站。
- 保留原有小说/剧本、设定、资产详情、镜头、分镜、提示词、任务、成员、设置、剪辑与基线页面。移动端保留导航抽屉，制作阶段横向滚动，桌面侧栏可折叠。
- 工作区页面按路由加载，减少项目入口一次下载的脚本。内容浏览、任务和查询状态独立为组件，便于后续逐页改造。

## 修复的数据与状态问题

1. `usePersistentState` 在不卸载组件而切换key时，原实现会把旧值写进新项目的key。现在先读取新key再持久化，并保留稳定的setter和函数式更新语义。
2. 工作台只把当前作品中有效的章节ID发送给后端；旧章节或其他作品的章节不会被误用。章节加载失败时明确降级到整个项目。
3. 全项目计数与局部画廊筛选分开。筛选某章不会让全项目准备情况错误地缩小。
4. 加载中、失败和真实空结果独立显示；核心数据未就绪时不生成“下一步”结论；失败可以重试，不能显示成零条数据。

## 复现

前端运行Vite预览时，设置 `APP_URL`（默认 `http://127.0.0.1:5187`）与 `ARTIFACT_DIR`。有本地Playwright依赖时直接运行；使用外部运行时则将 `PLAYWRIGHT_MODULE` 指向其 `playwright/index.mjs`。

- `node tests/workspace-regression.mjs`：模拟API的八组边界检查。
- `node tests/workspace-live.mjs`：现有账号的只读接口/页面检查，可用 `TEST_USERNAME`、`TEST_PASSWORD`、`TEST_PROJECT_ID` 指定测试账号和项目。
- `node --test tests/timeline-edit.test.mjs`：既有剪辑逻辑回归。
- `npm run build`：类型检查与生产构建。

测试报告和截图保存在本机任务产物目录的 `platform-rebuild/`：`live-report.json`、`regression-report.json`、`workbench-dark.png`、`workbench-light.png`、`workbench-mobile.png`、`projects.png`、`quick-navigation.png`、`empty-project.png`。

## 1. 通用约定

- **主键**:`id UUID`(默认 `gen_random_uuid()`),业务编号另存 `code`。
- **时间戳**:`created_at / updated_at TIMESTAMPTZ`,默认 `now()`。
- **软删除**:可删实体含 `deleted_at TIMESTAMPTZ NULL`;查询默认过滤非空。
- **归属**:几乎所有业务表含 `project_id`(隔离根 FK),并建索引。
- **审计**:写操作含 `created_by / updated_by`(User FK)。
- **灵活字段**:`metadata / params / config` 等用 `JSONB`。
- **命名**:表名单数蛇形(`asset`),枚举见第 3 章。

## 2. 横切内核模式(先理解这五个,再看具体表)

### 2.1 可版本化模式(Live 行 + 不可变快照)
- **Live 行**:实体自身表中持有"当前工作副本"(可改、可关系查询)。
- **快照**:`version` 表存不可变历史(JSONB 内容)。
- 实体表 `current_version_id` 指向最近一次提交的快照。
- **提交版本** = 把 Live 内容写入一条新 `version`;**回滚** = 取某快照内容写回 Live 行并再提一版。
- 适用实体:novel / outline / script / scene / shot / asset / prompt / prompt_fragment。

### 2.2 关系边(依赖图)
统一 `relation` 边表承载五类关系(改编/组成/引用/复用/组装)做**溯源与影响分析**。
其中"镜头→资产"这条**引用热路径**额外用强类型表 `shot_asset_ref`(承载浮动/钉死语义),`relation` 仅作图层冗余投影。

### 2.3 内容寻址存储(CAS)
所有二进制只入 `blob`(按 `hash` 去重),业务行仅持 `blob_hash` 指针;缩略图亦为 blob。

### 2.4 基线(整体冻结)
`baseline` + `baseline_item`:一次冻结一整套实体的指定 `version_id`,支持回溯/对比/并行方案;`cut`(成片)即一个基线化的时间线。

### 2.5 编码与序号
`code_sequence(project_id, entity_type)` 保存自增序号;编码规则(前缀/位宽)存 `project.settings`,生成形如 `PR-0042`、`SC012-SH003`。

## 4. 数据表定义(按模块)

> 列格式:**字段** · 类型 · 约束/说明

### 4.1 identity(身份与权限)

**user**
- id UUID PK · username UNIQUE · email UNIQUE · password_hash · display_name · is_active BOOL · created_at

**project**(隔离根)
- id UUID PK · code UNIQUE · name · description · owner_id→user · settings JSONB(编码规则/默认策略等) · created_at · deleted_at

**membership**
- id PK · project_id→project · user_id→user · role `role` · created_at · UNIQUE(project_id,user_id)

**audit_log**
- id PK · project_id→project · user_id→user · action · target_type · target_id UUID · detail JSONB · created_at · INDEX(project_id,created_at)

**code_sequence**
- project_id→project · entity_type · next_seq INT · PK(project_id,entity_type)

### 4.2 versioning 内核(横切)

**version**(不可变快照,多态)
- id PK · project_id · entity_type · entity_id UUID · version_no INT · label · status `version_status` · content JSONB · is_locked BOOL · created_by→user · created_at
- UNIQUE(entity_type,entity_id,version_no) · INDEX(entity_type,entity_id)
- 说明:多态 FK 不设库级外键,完整性由应用层 + 分区索引保证。

**relation**(依赖图边,多态)
- id PK · project_id · src_type · src_id · dst_type · dst_id · rel_type `relation_type` · ref_mode `ref_mode` NULL · pinned_version_id→version NULL · ordinal INT NULL · metadata JSONB · created_at
- INDEX(src_type,src_id) · INDEX(dst_type,dst_id)(反向溯源/影响分析)

**baseline**
- id PK · project_id · name · kind(rough/fine/final/custom) · note · created_by · created_at

**baseline_item**
- id PK · baseline_id→baseline · entity_type · entity_id · version_id→version · UNIQUE(baseline_id,entity_type,entity_id)

### 4.3 storage(CAS)

**blob**
- hash TEXT PK(内容哈希) · storage_uri(MinIO 路径) · mime · size_bytes BIGINT · width INT NULL · height INT NULL · duration_ms INT NULL · created_at

### 4.4 narrative(原著→剧本→场次)

**novel**
- id PK · project_id · code · title · source_format(txt/docx/...) · original_blob_hash→blob NULL · status `version_status` · current_version_id→version NULL · created_by · created_at · deleted_at

**chapter**(解析策略产出)
- id PK · novel_id→novel · ordinal INT · title · content TEXT · created_at · INDEX(novel_id,ordinal)

**outline**
- id PK · project_id · code · title · content TEXT · status · current_version_id · created_by · created_at · deleted_at

**script**
- id PK · project_id · code · title · status · current_version_id · created_by · created_at · deleted_at

**scene**
- id PK · project_id · script_id→script · code · ordinal INT · title · summary · body TEXT · adapted_from_chapter_id→chapter NULL(改编溯源) · status · current_version_id · created_by · created_at · deleted_at · INDEX(script_id,ordinal)

### 4.5 asset(蓝图资产库)

**asset**
- id PK · project_id · code · type `asset_type` · name · summary · status `version_status` · current_version_id · representative_blob_hash→blob NULL(代表图) · metadata JSONB(按类型模板) · tags TEXT[] · embedding VECTOR NULL(EXT-01 预留) · scope(project/global,EXT-05 预留默认 project) · created_by · created_at · deleted_at
- INDEX(project_id,type) · GIN(tags) · GIN(metadata)

**asset_reference_image**(参考图集/角色三视图)
- id PK · asset_id→asset · blob_hash→blob · role(ref/turnaround/expression) · note · ordinal

**metadata_template**(类型字段模板;EXT-10 自定义字段的雏形)
- id PK · project_id · target(asset/...) · asset_type `asset_type` NULL · schema JSONB · created_at

### 4.6 consistency(一致性)

**visual_identity**(角色/场景的视觉身份,一对一于 asset)
- id PK · asset_id→asset UNIQUE · strategy `consistency_strategy` · prompt_fragment_id→prompt_fragment NULL · lora_ref JSONB NULL(模型/触发词) · reference_set JSONB NULL(参考图组合规则) · config JSONB

### 4.7 prompt(提示词)

**prompt**
- id PK · project_id · code · name · positive TEXT · negative TEXT · status · current_version_id · tags TEXT[] · created_by · created_at · deleted_at

**prompt_fragment**(可复用片段)
- id PK · project_id · code · category(quality/camera/lighting/style/custom) · name · text TEXT · created_by · created_at · deleted_at

### 4.8 shot(镜头制作)

**shot**
- id PK · project_id · scene_id→scene · code · ordinal INT · title · description TEXT · production_status `production_status` · prompt_override TEXT NULL(覆写组合结果) · selected_generation_id→generation NULL(钦定代表片段) · assignee_id→user NULL · reviewer_id→user NULL · status `version_status` · current_version_id · created_by · created_at · deleted_at
- INDEX(scene_id,ordinal) · INDEX(project_id,production_status)(进度看板)

**shot_asset_ref**(镜头→资产 引用热路径,承载钉死语义)
- id PK · shot_id→shot · asset_id→asset · ref_mode `ref_mode` · pinned_version_id→version NULL · role(角色/道具/场景...) · ordinal
- UNIQUE(shot_id,asset_id,role) · INDEX(asset_id)(反查"该资产被哪些镜头用")

### 4.9 generation(生成生产)

**provider_config**(platform:供应商配置/密钥)
- id PK · project_id · provider_name(jimeng/...) · kind `provider_kind` · enabled BOOL · capabilities JSONB(能力声明) · endpoint · credentials_encrypted BYTEA(加密密钥) · config JSONB · created_at · UNIQUE(project_id,provider_name)

**quota**(成本配额)
- id PK · project_id · scope `quota_scope` · user_id→user NULL · limit_cost NUMERIC · used_cost NUMERIC · period(month/total) · reset_at · UNIQUE(project_id,scope,user_id)

**generation_job**(异步任务生命周期)
- id PK · project_id · target_type(shot/asset) · target_id UUID · provider · request_type `request_type` · status `job_status` · external_job_id NULL · priority INT · params JSONB · input_snapshot JSONB(**冻结**:组合后提示词、参数、模型、参考图版本指针) · estimated_cost NUMERIC · actual_cost NUMERIC NULL · error TEXT NULL · created_by · created_at · updated_at
- INDEX(project_id,status) · INDEX(status,priority)(调度)

**generation**(不可变溯源 + 变体)
- id PK · project_id · job_id→generation_job · target_type · target_id UUID · provider · model · seed · params JSONB · prompt_snapshot TEXT · input_refs JSONB(参考图/资产版本指针快照) · output_blob_hash→blob · output_type `request_type` · thumbnail_hash→blob NULL · rating INT NULL · is_favorite BOOL · is_selected BOOL · cost NUMERIC · embedding VECTOR NULL(EXT-01) · created_at
- INDEX(target_type,target_id) · 说明:行一经写入不更新(除评分/收藏/选定标志)。

### 4.10 timeline(时间线与成片)

**timeline**
- id PK · project_id · name · kind(main/sequence) · status · created_by · created_at · deleted_at

**timeline_item**(组装:镜头片段排序)
- id PK · timeline_id→timeline · shot_id→shot · generation_id→generation(用哪条定版片段) · ordinal INT · in_point_ms INT · out_point_ms INT · duration_ms INT · transition JSONB NULL · note · INDEX(timeline_id,ordinal)

**cut**(成片/剪辑基线)
- id PK · project_id · code · name · kind `cut_kind` · timeline_id→timeline · baseline_id→baseline NULL(定剪时冻结) · status · created_by · created_at

**audio_track**(EXT-11 预留)
- id PK · timeline_id · kind(dialogue/music/sfx) · blob_hash NULL · config JSONB —— *本期仅建表占位*

### 4.11 review(评审/批注/返修)

**review**
- id PK · project_id · target_type(shot/generation) · target_id UUID · generation_id→generation NULL · status `review_status` · round_no INT · requested_by→user · reviewer_id→user NULL · decision TEXT NULL · created_at · resolved_at NULL · INDEX(target_type,target_id)

**annotation**
- id PK · review_id→review · kind `annotation_kind` · geometry JSONB NULL(画面框选坐标) · timecode_ms INT NULL(视频批注) · comment TEXT · author_id→user · created_at

**revision**(返修轮次)
- id PK · review_id→review · shot_id→shot · round_no INT · note TEXT · created_at

## 5. 状态机

### 5.1 镜头制作状态 `production_status`
```
to_design ──设计──▶ concept ──提交生成──▶ generating ──产出──▶ pending_review
   ▲                                                              │
   │                                              ┌──通过──▶ approved ──排入──▶ in_cut
   └──────────── revising ◀──打回──────────────────┘
                    └──重新生成──▶ generating
```

### 5.2 生成任务 `job_status`
```
pending ─▶ submitted ─▶ running ─▶ succeeded
   └─▶ canceled        └─▶ failed ─(重试)▶ pending
```

### 5.3 版本生命周期 `version_status`
```
draft ─▶ review ─▶ locked(不可改,基线候选) ─▶ archived
                      └─(解锁需权限)▶ draft
```

### 5.4 评审 `review_status`
```
pending ─通过▶ approved
   └────打回▶ rejected ─▶ 生成 revision(round_no+1) ─▶ 新 review(pending)
```

## 6. ER 总览(聚合视图)

```
project 1─* membership *─1 user
project 1─* { novel→chapter, outline, script→scene, asset, prompt, prompt_fragment }
asset 1─1 visual_identity      asset 1─* asset_reference_image
scene 1─* shot
shot *─* asset  (经 shot_asset_ref, 带 ref_mode/pinned)
shot 1─* generation_job 1─* generation ─*─1 blob
shot.selected_generation_id ─▶ generation
timeline 1─* timeline_item ─1 shot / ─1 generation
cut ─1 timeline · cut ─1 baseline
baseline 1─* baseline_item ─1 version
version *── (entity_type,entity_id) ──多态── 各可版本化实体
relation: 任意实体 ── 任意实体 (溯源/影响分析)
review 1─* annotation · review 1─* revision
provider_config / quota / audit_log ── project 级
```

## 7. 完整性与索引要点

- **多态表**(version/relation/audit_log/review):不设库级 FK,应用层保证;按 `(entity_type,entity_id)` 建复合索引支撑双向遍历。
- **反向溯源索引**:`shot_asset_ref(asset_id)`、`relation(dst_type,dst_id)`、`generation(target_type,target_id)`。
- **进度看板**:`shot(project_id,production_status)`。
- **调度**:`generation_job(status,priority)`。
- **去重**:`blob.hash` 主键天然去重。
- **JSONB 查询**:`asset.metadata`、`tags` 建 GIN。
- **向量检索**:`asset.embedding`、`generation.embedding` 预留 `pgvector`,本期不建索引。

## 8. 已确认决策(评审锁定)

| # | 议题 | 决策 |
|---|---|---|
| M1 | 版本快照存储 | **统一多态 `version` 表 + JSONB 快照**(表少、扩展快) |
| M2 | 镜头→资产引用 | **强类型 `shot_asset_ref` 热路径 + `relation` 图投影**(双写,查询快) |
| M3 | 成本计量口径 | **统一折算"点数(points)"**,并保留供应商原始计费值 |

### 8.1 成本字段落地(M3)
`generation_job` / `generation` 的成本字段明确为:
- `cost_points NUMERIC` —— 统一折算点数(配额、看板、比较均以此为准)
- `cost_raw JSONB` —— 供应商原始计费快照(币种/单价/数量,便于审计与对账)
> `provider_config.config` 内维护各供应商"原始计费 → 点数"的折算系数。

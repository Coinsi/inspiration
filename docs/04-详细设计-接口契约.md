## 1. API 通用约定

- **Base path**:`/api/v1`;资源复数名词,动作类用子路径动词(`/shots/{id}:generate`)。
- **认证**:`Authorization: Bearer <JWT>`;JWT 载荷含 `user_id`;项目上下文由路径 `project_id` 或头 `X-Project-Id` 给出。
- **内容类型**:`application/json`;文件上传走 `multipart/form-data`。
- **统一成功响应**:直接返回资源对象或集合(集合带分页包装)。
- **统一错误响应**:
  ```json
  { "error": { "code": "QUOTA_EXCEEDED", "message": "项目点数不足", "detail": {} } }
  ```
- **分页**:`?page=1&size=20&sort=-created_at`;集合返回 `{ "items": [...], "total": 123, "page": 1, "size": 20 }`。
- **过滤**:`?type=character&status=locked&tag=主角&q=关键字`。
- **幂等**:生成提交等写操作支持 `Idempotency-Key` 头,重复键返回同一结果。
- **软删**:`DELETE` 为软删(进回收站);`POST /{id}:restore` 恢复。
- **乐观锁**:可版本化资源更新带 `If-Match: <current_version_no>`,冲突返回 409。

## 4. 策略接口契约(可插拔扩展点核心)

> 以 Python ABC + Pydantic 模型表达。所有策略经各自 Registry 注册与解析。

### 4.1 通用注册中心
```python
class Registry(Generic[T]):
    def register(self, name: str): ...            # 装饰器,注册策略类
    def resolve(self, name: str) -> T: ...         # 取实例
    def match(self, required: Capabilities) -> list[T]: ...  # 按能力筛选
    def list(self) -> list[ProviderInfo]: ...      # 列出已注册(名称/能力/启用)
```

### 4.2 共享数据结构
```python
class Capabilities(BaseModel):
    modalities: set[Literal["image", "video"]]
    features: set[str]            # img2img / inpaint / controlnet / reference / lora ...
    max_reference_images: int = 0
    max_video_seconds: float | None = None
    param_schema: dict            # 供应商私有参数的 JSON Schema(前端动态渲染)

class GenerationRequest(BaseModel):
    request_type: Literal["image", "video"]
    prompt: str                   # BOM 组合后的最终正向提示词
    negative: str | None = None
    references: list[ReferenceImage] = []   # 参考图(blob_hash + role)
    seed: int | None = None
    params: dict = {}             # 标准化参数(steps/cfg/size/duration...)
    provider_params: dict = {}    # 供应商私有参数袋(校验于 param_schema)
    count: int = 1                # 出多少变体

class JobHandle(BaseModel):
    external_job_id: str
    raw: dict = {}

class GenerationResult(BaseModel):
    status: Literal["running", "succeeded", "failed"]
    outputs: list[Output] = []    # 每个含 二进制/URL + 类型 + 元信息
    cost_raw: dict | None = None  # 供应商原始计费快照
    error: str | None = None
```

### 4.3 生成供应商
```python
class GenerationProvider(ABC):
    name: str
    def capabilities(self) -> Capabilities: ...
    def estimate_cost(self, req: GenerationRequest) -> CostEstimate: ...   # 点数预估
    def submit(self, req: GenerationRequest) -> JobHandle: ...
    def poll(self, handle: JobHandle) -> GenerationResult: ...
    def cancel(self, handle: JobHandle) -> None: ...
    def verify_callback(self, payload: dict, headers: dict) -> bool: ...   # webhook 验签
```

### 4.4 小说解析
```python
class NovelDocument(BaseModel):
    title: str
    chapters: list[Chapter]       # Chapter(ordinal, title, content)

class NovelParser(ABC):
    name: str
    def can_handle(self, filename: str, mime: str) -> bool: ...
    def parse(self, file: BinaryIO) -> NovelDocument: ...
```

### 4.5 AI 辅助拆解
```python
class DecompositionStrategy(ABC):
    name: str
    def suggest_scenes(self, chapter_text: str) -> list[SceneSuggestion]: ...
    def suggest_shots(self, scene_text: str) -> list[ShotSuggestion]: ...
    def extract_entities(self, text: str) -> list[EntityDraft]: ...   # 角色/道具/场景
    def draft_prompt(self, scene_text: str, shot: ShotSuggestion) -> str: ...
```

### 4.6 一致性
```python
class ConsistencyStrategy(ABC):
    name: Literal["prompt", "reference", "lora"]
    def apply(self, base: GenerationRequest, identities: list[VisualIdentity]) -> GenerationRequest:
        """把角色/场景的视觉身份注入请求:拼提示词 / 加参考图 / 挂 LoRA 触发词"""
```

## 5. 即梦(Jimeng)适配器映射

`JimengProvider(GenerationProvider)`,`name="jimeng"`,V1 首批同时实现图像 + 视频。

| 抽象层 | → 即梦侧 |
|---|---|
| `capabilities()` | `modalities={image,video}`;features 含 `reference`;`max_video_seconds` 按即梦档位填;`param_schema` 暴露即梦特有参数(画幅/时长/运动幅度等) |
| `GenerationRequest.prompt/negative` | → 即梦文生图/文生视频提示词字段 |
| `references` | → 即梦图生图/图生视频参考图入参 |
| `params`(标准) + `provider_params`(私有) | → 即梦请求体;标准参数做映射,私有参数透传 |
| `submit()` | → 即梦异步任务提交,取回任务 id 存 `external_job_id` |
| `poll()` / `verify_callback()` | → 即梦任务查询 / 回调验签 |
| `GenerationResult.outputs` | → 下载产物入 CAS `blob`,生成缩略图 |
| `cost_raw` | → 即梦计费快照;经 `provider_config.config` 折算系数 → `cost_points` |

> 密钥与端点存 `provider_config`(加密);即梦协议细节封装在适配器内,领域层不感知。

## 6. 错误码表(节选)

| code | HTTP | 含义 |
|---|---|---|
| `UNAUTHORIZED` | 401 | 未登录/令牌失效 |
| `FORBIDDEN` | 403 | 角色无权限 |
| `NOT_FOUND` | 404 | 资源不存在/已软删 |
| `VERSION_CONFLICT` | 409 | 乐观锁冲突(If-Match 不符) |
| `CAPABILITY_UNSUPPORTED` | 422 | 供应商不支持该请求能力 |
| `QUOTA_EXCEEDED` | 402 | 项目/用户点数不足 |
| `PROVIDER_ERROR` | 502 | 上游生成供应商错误 |
| `LOCKED` | 423 | 实体已锁定不可改 |

## 7. 已确认决策(评审锁定)

| # | 议题 | 决策 |
|---|---|---|
| A1 | 项目上下文 | **统一路径方案** `/api/v1/projects/{pid}/...`,不用 `X-Project-Id` 头 |

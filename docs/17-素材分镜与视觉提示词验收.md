## 已交付的流程

1. **资产浏览 → 快速预览 → 完整详情或生成**：卡片和列表采用同一排序；搜索与标签输入延迟250毫秒请求；预览展示代表图、描述、参考图和真实计数。保留图谱、上传、版本、编辑与回收站入口。加载失败显示重试，不当作零素材。
2. **批量选择 → 筛选切换**：退出旧选择范围；锁定项不参与全选；删除仅发送当前有效选择，确认弹窗固定当时的ID列表。后端跳过的数量会提示。项目切换重建页面临时状态。
3. **场景 → 画面浏览 → 分镜编辑或镜头详情**：新增场景查找、画面卡片和快速预览；原有对白、声音、景别、运镜、拖动/按钮排序与AI拆分继续可用。选定画面数与审阅通过数分开显示。小说、章节与场景ID先在当前范围内验证，避免把过期ID发给后端。
4. **选择参考图片 → 看图整理提示词 → 手动采用**：保留三种文字模式，增加“结合参考”和“适配生成能力”。可从当前对象的图片版本、资产上传参考图或其他项目内资产选图，最多4张。结果可编辑，显示优化模型、实际参考来源和新增假设。采用只更新当前生成输入框，不生成图片、不改变资产代表图。
5. **选择两个图片版本 → 并排比较 → 按需采用**：展示完整图片、提示词快照、供应商与已有来源记录，支持放大；采用复用原有版本选择接口。音频和视频不参与这次图片比较。

## 参考图发送与权限

浏览器提交 `kind + id`，不提交任意URL或裸存储hash。服务器校验生成记录/资产参考图属于当前项目，并校验所属对象未删除，然后从既有文件存储读取。

每张原图限制20 MB、4000万像素；发送给文本模型的是最长边1024像素的JPEG预览，保留原素材不变。透明部分铺白。跨项目、已删除对象、非图片、重复引用、超额和损坏图片在模型调用前被拒绝。结果中的参考来源由服务器填写，不信任模型自报来源。审计记录参考ID/hash、优化模式、优化模型和目标供应商，不记录base64图片或凭据。

“适配生成能力”使用实际供应商能力声明，检查图片/视频类型支持；不虚构模型参数或修改生成设置。这次没有宣称完成各模型独有技巧的调优。

## 明确边界与后续

- 当前素材库仍是创作资产与版本库；大视频导入、代理预览、片段引用及安全删除属于下一批，并未因增加浏览界面就完成。
- 视觉输入当前仅图片。需要项目文本模型支持看图；其他供应商尚无真实看图验收。本次模型文字混入一个英文肤色词，且对材质有推断，结果仍需人工核对，不能当身份事实。
- 参考图用于提示词理解，不自动加入生成参考集合；图片生成继续遵循原有资产引用/源图配置。
- 优化记录写入审计，生成保存提示词快照和既有来源；**尚无优化记录到后续生成记录的显式关联**，也没有持久的优化对话历史、流式输出或服务端取消。关闭优化窗口不等于撤销已发送的模型请求。
- 图片比较是并排查看，尚未加入滑块叠加和视频同步比较。真实项目只验证读取比较；实际选择写入由隔离数据库测试和浏览器模拟验证。

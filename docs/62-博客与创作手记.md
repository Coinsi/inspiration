# 博客与创作手记

2026-09-26：官网加入博客入口、最新三篇文章区及独立阅读页面。沿用官网的浅色、绿色和细线视觉，采用编辑式留白、纸张插画封面、正文目录与适配手机的阅读宽度。

## 使用

- `/blog`：公开文章，支持分类、全文关键词搜索、分页；分类为创作指南、产品更新、灵感笔记。
- `/blog/:slug`：独立阅读地址，支持 Markdown 标题、列表、引用、代码块、表格和链接。
- `/admin/blog`：平台管理员文章列表、归档列表，官网管理页右上角也有入口。
- `/admin/blog/new`：填写标题、摘要和正文，选择分类、署名及封面；地址留空则自动生成，首次保存后固定。
- 先保存草稿、预览，确认后单独发布。保存修改不会改变已公开的版本。下线保留草稿；归档可恢复，恢复不会自动发布。
- 封面可从官网素材库选择或上传 JPG/PNG/WebP 原图；未提供封面时使用内置手记插画。正文暂不支持插入图片或任意 HTML。

## 数据及边界

迁移 `0023_blog` 创建 `blog_post`，独立存储草稿与已发布快照。写操作使用行锁和版本校验；过期版本返回冲突，编辑器允许重新载入。项目管理员不能管理公开博客。

公开列表和详情只查询未归档且已发布的快照，搜索也不读取未发布草稿。封面复用官网媒体登记表和 CAS，只有被当前已发布文章或官网启用板块引用时才能匿名读取；多个公开内容共享封面时，下线其中一篇不会撤销其他引用。管理员预览通过认证读取，不把认证令牌加入地址。

此阶段沿用 SPA 路由，没有新增评论、订阅邮件、定时发布、服务端 SEO 渲染、社交分享卡片或可视化富文本编辑器。

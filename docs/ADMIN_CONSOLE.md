# 平台管理后台

入口为 `/admin`，管理员也可以从头像菜单的“平台管理”进入。后台采用独立导航和布局，复用现有服务、账号和数据库；创作空间与个人模型配置保持独立。

## 当前能力

| 页面 | 功能 |
| --- | --- |
| 概览 | 用户、项目、任务、登记文件体积和生成用量，进入需要关注的任务 |
| 用户管理 | 分页搜索注册账号，按状态/角色筛选，查看登录时间、项目/作品数量、相关任务和个人项目额度 |
| 模型服务 | 平台全局模型、渠道、默认模型及已有连接检查 |
| 任务中心 | 生成、制作运行、素材上传、对话附件、索引、媒体处理、转写和工程归档的运行元数据 |
| 用量与额度 | 查看并调整已有内部项目/用户项目额度，保留版本校验和操作原因 |
| 官网内容 | 草稿、素材、预览、发布、历史恢复及操作记录 |
| 博客文章 | 编辑、发布/撤回、归档及操作记录 |
| 系统状态 | 存储概况、未完成上传、服务配置、保留策略和手动健康检查 |
| 操作记录 | 平台操作的操作者、时间、动作、目标及账号/额度变更原因 |

## 多管理员与权限

- 普通用户、项目管理员没有平台后台权限。
- 平台管理员可查看运营信息，维护全局模型、官网和博客。
- 超级管理员另可禁用/恢复账号、退出账号的全部会话、授权/撤销管理员、调整内部额度。
- 账号变更采用事务锁与版本校验，避免并发覆盖；不能撤销最后一位有效超级管理员。
- 账号安全变更撤销现有登录会话。禁用不删除历史作品，也不自动取消已提交任务。
- 平台身份不授予私人项目访问权。任务只展示安全诊断，不展示提示词、私有文件名、原始错误或密钥；进入项目仍需已有成员权限。

迁移 `0057_platform_admin` 将已有平台管理员设为超级管理员，不向普通账号自动授权。部署须先执行项目原有数据库升级流程。初始授权保留服务器命令（在后端环境运行）：

```powershell
python -m app.modules.website.admin grant <已注册用户名>
```

`revoke` 同样受最后一位超级管理员保护。后台可由超级管理员给其他已注册用户授权，无需共享账号。

## 数据含义与边界

- 最近登录从成功登录开始记录，不补造历史时间。
- 文件体积来自去重 Blob 登记记录，不是磁盘剩余空间或供应商账单。
- 生成用量沿用内部单位，不代表人民币；缺失实际用量单独计数。
- 额度管理针对已有记录，不包含商业套餐、充值、退款或新的计费系统。
- 需要关注包含历史失败与待处理记录，不代表当前全站故障。
- 旧上传及索引表没有操作者字段时显示“未记录”，按用户筛选不会推测归属。
- 健康检查反映当前服务/API 进程，不等于所有节点监控或真实模型生成验证。
- 不增加强制重试状态不明的付费请求或批量删除私人素材入口；恢复沿用原业务规则。
- 官网、博客编辑点击后台导航离开时提示未保存修改；刷新/关闭沿用浏览器离开提醒。

## 验证方式

`backend/tests/test_platform_admin.py` 使用隔离 PostgreSQL schema，验证迁移、角色、会话撤销、并发保留超级管理员、额度冲突、分页及跨类型任务信息隔离；相关账号、第三方登录、官网、博客和全局模型测试一并回归。

`frontend/tests/admin-console-live.mjs` 对隔离本地 API/数据库执行真实浏览器操作：禁用/恢复、刷新读回、相关任务、编辑离开提醒、服务检查、三种身份和手机布局。无接口拦截或付费模型调用。运行需要隔离环境准备测试账号，并提供 `ADMIN_TEST_URL`、`ADMIN_TEST_PASSWORD` 和 `PLAYWRIGHT_MODULE`；不得使用生产数据库。

截图与结果位于 `test-results/admin-console/`。全局模型页面另有 `frontend/tests/platform-models-browser.mjs` 的确定性接口模拟测试。本地验收不替代部署后的迁移与线上业务验收。

本次验证结果（2026-11-16）：相关后端回归 90 项通过；补充任务状态后 8 项后台专属测试再次通过；真实本地浏览器与全局模型模拟浏览器验收通过；前端构建通过。未部署到线上。

## 1. 原则

- **垂直切片**:每个里程碑交付端到端可用的一小块(后端 + 前端 + 测试),而非按层堆叠。
- **前后端同步**(决策 H4):每个里程碑同时推进对应前端页面与 API 联调。
- **闭环优先**:尽早跑通"导入→拆解→生成→成片"主干,边角功能后补。
- **每里程碑出口**:迁移可用、Swagger 可联调、关键路径有测试、可演示。

## 3. 里程碑详情

### M0 · 工程地基
**后端**
- `backend/` 骨架(core/kernel/modules/adapters/registry/tasks)、FastAPI 入口、配置(pydantic-settings)、健康检查。
- `deploy/docker-compose.yml`:api / worker / postgres(+pgvector)/ redis / minio / web。
- Alembic 初始化 + **全量建表迁移**(对照 [03 数据模型](03-详细设计-数据模型.md))。
- identity:User/Project/Membership、JWT 登录、**权限网关中间件**、审计装饰器。
- storage:CAS `blob` 落 MinIO + 缩略图;narrative 用的文件上传。
- platform:`code_sequence` 编码生成器。

**前端**
- Vite + React + TS + Tailwind + shadcn/ui 骨架;登录页、项目列表/新建、成员授权页。

**验收**:`docker compose up` 全绿;登录→建项目→授权成员→上传文件入 MinIO;`/docs` Swagger 可见。

### M1 · 资产库 + 版本内核
**后端**
- asset CRUD + 类型模板元数据 + 参考图集 + 软删/回收站/恢复。
- **versioning 内核**:`version` 快照(提交/列表/diff/rollback/lock)。
- `relation` 边表 + `:usages` 反查 + `:impact` 影响分析(floating/pinned 区分)。

**前端**
- 资产网格(分面筛选)、资产详情(元数据/参考图)、版本历史与 diff、回收站。

**验收**:建资产→改→提交版本→回滚→锁定→反查"被哪些镜头引用"(此时镜头未建,接口先就绪)。

### M2 · 内容拆解 + AI 辅助
**后端**
- narrative CRUD(novel/outline/script/scene)。
- **NovelParser 策略**:txt/docx/markdown;`:import` 异步落 novel+chapters。
- **DecompositionStrategy(云 LLM)**:suggest_scenes / suggest_shots / extract_entities / draft_prompt。
- suggestion 暂存 + `:apply` 人工确认落库。

**前端**
- 拆解工作台:小说导入、章节树、AI 拆解建议(可编辑确认)、实体抽取→资产卡草稿。

**验收**:导入一部 txt 小说→AI 建议场次与镜头→编辑确认→落库;抽取角色/道具生成资产草稿。

### M3 · 提示词 + 一致性 + 镜头
**后端**
- prompt / prompt_fragment CRUD;`:compose-prompt` **BOM 组合预览**。
- visual_identity + **一致性三策略**(prompt/reference/lora)。
- shot CRUD;`asset-refs`(ref_mode/pinned);**制作状态机** `:transition`;**进度看板** `/shots/board`。

**前端**
- 提示词编辑器 + 片段库;镜头列表/详情;一致性配置;进度看板。

**验收**:镜头引用角色/场景→自动组合出最终提示词→套用一致性→状态机流转→看板计数正确。

### M4 · 生成生产(即梦) ★达成首个生产闭环
**后端**
- platform:`provider_config`(密钥加密)、Registry、Capabilities 能力声明。
- **GenerationProvider 抽象 + JimengProvider(图像 + 视频)**。
- generation_job 生命周期 + Celery **worker 轮询**(决策 A3)+ 产物入 CAS + 缩略图。
- 配额校验、`:estimate` 成本预估、点数记账(cost_points + cost_raw)。
- 变体评分/收藏/`:select` 钦定;`:batch` 批量 + 影响分析驱动重生成。

**前端**
- 生成工作台:参数表单(按 capabilities 动态渲染)、成本预估、变体墙、评分/钦定;任务进度轮询。

**验收**:对镜头触发即梦生成→出图与出片→入库为变体→钦定代表版→镜头转"定版";配额不足被拦截;成本入账。**至此小说→拆解→生成→定版闭环可演示。**

### M5 · 评审 + 时间线 + 成片基线
**后端**
- review/annotation/revision + `:decide`(打回生成 revision,联动状态机)。
- timeline/timeline_item(in/out/转场)、cut、`:finalize`→冻结 **baseline**。
- baseline create/compare。

**前端**
- 评审界面(画面框选/视频时间码批注)、时间线编辑器、成片基线管理与对比。

**验收**:发起评审→批注→打回返修→通过定版→排入时间线→定剪冻结基线→两基线可对比。

## 4. 横切与质量

- **测试**:每里程碑核心服务带单元测试;关键路径(生成编排、版本回滚、影响分析、权限)带集成测试。
- **迁移**:每里程碑新增表/字段走 Alembic 增量迁移。
- **种子数据**:提供 demo 项目种子(一部样例小说 + 角色/场景),便于演示与回归。
- **扩展点**:M4 起即按策略接口落地,后续接新供应商/格式仅加适配器。

---

## 5. 建议起步

从 **M0 工程地基** 开始:搭 `backend/` + `docker-compose` + Alembic 全量建表 + 登录/项目/权限骨架。这是后续一切的承载体。

## 1. 引言

### 1.1 编写目的
明确 Inspiration 平台 **做什么**(功能性需求)与 **达到什么标准**(非功能性需求),作为后续概要设计、详细设计、编码与验收的唯一需求依据。本文档读者:产品、架构、开发、测试。

### 1.2 项目背景
传统影视/动漫制作流程长、资产多、版本乱、协作难;AIGC 引入后,生成内容爆炸式增长且需多方模型协同。本项目将**制造业的资产管理与配置管理思想**引入 AIGC 影视生产,解决"资产可复用、版本可追溯、流程可协作、成片可复现"四大痛点。

### 1.3 术语
见 [00-术语表](00-术语表.md)。

### 1.4 需求优先级定义
- **P0 必须(Must)**:V1 核心闭环,缺失则产品不成立。
- **P1 重要(Should)**:V1 应实现,显著影响体验。
- **P2 可选(Could)**:V1 视资源实现。
- **EXT 扩展点(Reserved)**:本期**仅预留接口/数据位**,不实现功能。

## 2. 项目概述

### 2.1 产品定位
**双重身份**:既是**资产库**(静态:资产 + 关系 + 版本),又是 **AIGC 生产平台**(动态:把资产喂给策略产出新资产,直至成片)。

### 2.2 产品目标
1. 贯通"小说→成片"全链路,任一环节可正向拆解、反向溯源。
2. 以提示词 BOM 组合 + 一致性管理,解决 AIGC 角色/画风一致性难题。
3. 以可插拔策略对接多方图/视频生成模型,扩展零侵入核心。
4. 以版本/基线配置管理,保证任意历史方案可复现、可对比。
5. 支持多人按角色协作,关键操作受控可审计。

### 2.3 用户角色与画像
| 角色 | 关注点 | 典型操作 |
|---|---|---|
| 管理员 | 项目、成员、配额、供应商配置 | 建项目、授权、配额、接模型 |
| 编剧 | 大纲、剧本、拆解 | 导入小说、写大纲剧本、拆场次 |
| 导演 | 镜头、评审、成片 | 定镜头、审片、定剪 |
| 美术 | 资产、提示词、一致性、生成 | 建角色/场景、调提示词、出图 |
| 制片 | 进度、成本、物料 | 看进度看板、控成本、出物料表 |
| 访客 | 只读查看 | 浏览、评论 |

### 2.4 范围
- **本期纳入(P0/P1)**:见第 4 章各模块标注。
- **本期不做(EXT)**:见第 6 章扩展点清单。

### 2.5 假设与依赖
- 依赖外部生成模型(自建 ComfyUI / 第三方 API),其可用性与计费由供应商决定。
- 大文件存储依赖对象存储(本地 MinIO 起步)。
- AI 辅助拆解依赖外部 LLM 服务。

## 3. 业务流程需求

### 3.1 总体流程(P0)
系统须支持完整业务闭环:**拆解(原著→大纲→剧本→场次→镜头)→ 生产(镜头出图/出片)→ 组装(镜头→时间线→成片)**,各阶段产物互相关联、可溯源。

### 3.2 核心关系(P0)
- 改编关系:场次 ⟶ 原著章节
- 组成关系:剧本→场次→镜头(BOM)
- 引用关系:镜头 ⟶ 资产 / 提示词
- 复用关系:同一资产被多镜头引用
- 组装关系:镜头 ⟶ 时间线位置

## 4. 功能性需求

> 编号规则:`FR-<模块号>-<序号>`。

### 4.1 资产库管理(模块 01)
- **FR-01-01 (P0)** 支持新建/编辑/归档资产,类型含:角色、道具、场景/置景、服化道、载具、风格模板、提示词、模型/LoRA。
- **FR-01-02 (P0)** 每个资产具备唯一编号(可配置编码规则,如 `PROP-0042`)。
- **FR-01-03 (P0)** 每个资产挂载元数据(键值/标签),元数据字段由类型模板定义。
- **FR-01-04 (P0)** 资产可上传/关联参考图与代表图(缩略图)。
- **FR-01-05 (P0)** 支持正向查询(资产含哪些子项)与反向查询(资产被哪些镜头引用)。
- **FR-01-06 (P1)** 资产支持分类、标签、关键字基础检索与分面筛选。
- **FR-01-07 (P0)** 资产删除为软删除,进回收站,可恢复。

### 4.2 内容拆解(模块 02)
- **FR-02-01 (P0)** 支持导入小说,**多格式经解析策略**统一为结构化文档(章节→段落)。本期至少支持 txt、docx、markdown;epub/pdf 经策略扩展。
- **FR-02-02 (P0)** 支持人工创建/编辑大纲、剧本、场次、镜头,维护其层级与编号。
- **FR-02-03 (P0)** 场次可关联到原著章节,实现改编溯源。
- **FR-02-04 (P0)【AI 辅助拆解】** 支持调用 LLM 策略:由章节/剧本**自动建议**场次切分与镜头列表,人工确认后入库。
- **FR-02-05 (P0)【AI 辅助拆解】** 支持从剧本/场景文本**自动抽取实体**(角色/道具/场景),一键生成资产卡草稿。
- **FR-02-06 (P1)【AI 辅助拆解】** 支持依据场景描述**自动起草镜头提示词**。
- **FR-02-07 (P1)** AI 拆解为可插拔策略,可切换不同 LLM 供应商。

### 4.3 提示词管理与组合(模块 03)
- **FR-03-01 (P0)** 提示词为一等资产,支持正向/负向、标签、版本。
- **FR-03-02 (P0)** 支持可复用提示词片段库(画质、镜头、光照等)。
- **FR-03-03 (P0)【BOM 组合】** 镜头最终提示词由其引用资产的提示词片段 + 场景描述 + 风格模板**自动拼装**生成,且可人工覆写。
- **FR-03-04 (P0)** 修改某资产的提示词片段,可触发引用它的镜头的**影响分析**(见 4.9)。

### 4.4 生成生产(模块 04)
- **FR-04-01 (P0)【策略】** 生成引擎以**生成供应商策略**接入,支持多供应商注册、启用/禁用、能力声明。
- **FR-04-02 (P0)** 支持**图片生成**;**视频生成**作为同一任务模型下的策略。**本期落地即梦(Jimeng)适配器,打通图像 + 视频两条生成链路**(决策 D1)。
- **FR-04-03 (P0)** 生成请求含标准化字段(类型/提示词/参考图/seed/参数)+ 供应商私有参数袋。
- **FR-04-04 (P0)** 提交前进行**能力协商**:不支持的请求被前置拦截并明确提示。
- **FR-04-05 (P0)** 生成为**异步任务**,具备生命周期(pending→submitted→running→succeeded/failed/canceled),支持轮询或回调。
- **FR-04-06 (P0)** 每次生成产生**不可变溯源记录**:冻结提示词内容、参数、模型、参考图版本。
- **FR-04-07 (P0)** 一个资产可有多次生成 → 多变体;支持评分、收藏、**钦定代表版**,保留全部历史。
- **FR-04-08 (P1)** 支持**批量生成**(如对受影响镜头一键重生成),具备队列、限流、失败重试、部分续跑。
- **FR-04-09 (P0)【成本配额】** 生成前**预估成本**;按项目/用户设**配额**;超额拦截。
- **FR-04-10 (P1)【成本配额】** 记录每次生成实际成本/算力消耗,提供项目消耗汇总。
- **FR-04-11 (P0)【成本配额】** **触发生成**为受控权限点(见模块 09)。

### 4.5 一致性管理(模块 05)
- **FR-05-01 (P0)** 角色/场景资产支持**视觉身份**:参考图集、三视图/表情集、绑定 LoRA/风格模型、专属提示词片段。
- **FR-05-02 (P0)【策略】** 一致性方案以**一致性策略**实现,可切换:纯提示词拼装 / 参考图 reference / LoRA。
- **FR-05-03 (P0)** 风格模板(style bible)可在项目级或镜头级应用,保证画风统一。
- **FR-05-04 (P1)** 镜头生成时自动套用其引用角色/场景的一致性配置。

### 4.6 镜头制作管理(模块 06)
- **FR-06-01 (P0)** 镜头持有**两类关系**:隶属场次(拆解)+ 时间线位置(组装)。
- **FR-06-02 (P0)** 镜头具备**制作状态机**:待设计→概念图→生成中→待审→返修→定版→已入剪。
- **FR-06-03 (P0)** 镜头记录引用资产(支持版本钉死)、生成产物、定版片段、负责人/审核人。
- **FR-06-04 (P0)** 提供**进度看板**:全片镜头总数及各状态分布(如"480 镜,定版 312")。

### 4.7 时间线与成片组装(模块 07)
- **FR-07-01 (P0)** 支持将镜头定版片段排入**时间线**:顺序、入出点、时长、转场。
- **FR-07-02 (P0)** 成片(Cut)作为顶层交付物,其版本即整片**基线**:粗剪/精剪/定剪。
- **FR-07-03 (P1)** 成片完成度由镜头状态自动汇总。
- **FR-07-04 (EXT)** 音轨层(对白/配乐/音效)、字幕——预留数据位与策略接口。
- **FR-07-05 (EXT)** 导出到 NLE(EDL/XML/AAF)——预留导出策略接口。

### 4.8 评审 / 批注 / 返修(模块 08)
- **FR-08-01 (P0)** 对产出资产(图/片)发起评审,具备审批闸门:通过 / 打回。
- **FR-08-02 (P0)** 支持在画面上**框选标注**、给视频打**时间码评论**。
- **FR-08-03 (P0)** 打回生成**返修轮次**记录,带意见,关联到具体版本。
- **FR-08-04 (P1)** 评审状态联动镜头制作状态与权限。

### 4.9 版本与基线管理(模块 09)
- **FR-09-01 (P0)** 文本类资产(小说/大纲/剧本/提示词)支持**修订线**:历史、diff、回滚。
- **FR-09-02 (P0)** 产出类资产支持**变体集合**与代表版钦定(见 FR-04-07)。
- **FR-09-03 (P0)** 引用关系支持**浮动 / 钉死**两种模式及模式切换。
- **FR-09-04 (P0)【影响分析】** 修改上游资产版本,系统列出受影响下游(区分浮动已波及 / 钉死可升级),支持批量处理。
- **FR-09-05 (P0)** 支持创建**基线**:冻结一整套实体及版本(大纲+剧本+场次+镜头+资产+提示词)。
- **FR-09-06 (P0)** 支持回到任意基线、对比两个基线、并行推进多方案。
- **FR-09-07 (P1)** 版本具备生命周期状态(草稿→评审→锁定/定稿→归档);锁定后不可改。
- **FR-09-08 (EXT)** 分支与合并(并行探索结局 A/B)——预留模型支持。

### 4.10 多人协作与权限(模块 10)
- **FR-10-01 (P0)** 以**项目**为数据与权限隔离边界,一切资产归属某项目。
- **FR-10-02 (P0)** 用户在项目内被授予**角色**(管理员/导演/编剧/美术/制片/访客)。
- **FR-10-03 (P0)** 关键操作受权限控制:锁定/定稿、创建基线、触发生成、审批、配额管理。
- **FR-10-04 (P0)** 全量**审计日志**:谁在何时改了什么、触发了哪次生成。
- **FR-10-05 (P1)** 资产并发编辑支持锁定/检入检出,防冲突。
- **FR-10-06 (EXT)** 通知 / @提醒 / 活动流——预留接口。

### 4.11 检索(模块 11)
- **FR-11-01 (P1)** 支持跨资产类型的关键字 + 标签 + 分面检索。
- **FR-11-02 (EXT)** 基于 CLIP/embedding 的"以图搜图"相似检索——预留向量字段与接口。

## 5. 非功能性需求

### 5.1 性能
- **NFR-P-01** 资产列表、检索结果首屏响应 < 2s(万级资产)。
- **NFR-P-02** 生成任务异步化,提交接口不阻塞,< 500ms 返回任务句柄。
- **NFR-P-03** 视频预览须支持低码率代理,拖动流畅(代理转码为 EXT)。

### 5.2 可扩展性
- **NFR-E-01** 新增生成供应商/解析格式/AI 策略,**仅新增策略类 + 注册一行**,不改核心代码(开闭原则)。
- **NFR-E-02** 元数据字段可由类型模板扩展(自定义字段引擎为 EXT,本期用模板)。

### 5.3 可靠性与数据安全
- **NFR-R-01** 创作资产**禁止硬删除**,软删除 + 回收站 + 可恢复。
- **NFR-R-02** 溯源记录与基线**不可篡改**。
- **NFR-R-03** 二进制采用内容寻址存储,版本不复制大文件。

### 5.4 安全
- **NFR-S-01** 供应商 API Key 等密钥加密存储,按项目隔离。
- **NFR-S-02** 一切访问经权限网关校验,越权操作拒绝并记审计。

### 5.5 兼容性与可维护性
- **NFR-C-01** 后端 Python 技术栈,Web 前后端分离。
- **NFR-C-02** 策略层与生成引擎解耦,不绑定任一供应商。
- **NFR-C-03** 关键模块具备单元/集成测试。

## 7. 约束与边界

- 本期**不自研生成模型**,只做编排与管理。
- 本期成片**不做专业级剪辑/调色**,时间线为轻量组装,专业剪辑走 NLE 导出(EXT)。
- 多人协作本期为**项目级 RBAC**,资源级 ACL 与实时协同为后续演进。

---

## 8. 验收标准概要

V1 验收须满足:可导入一部小说 → AI 辅助拆出场次与镜头 → 建立角色/场景资产并配置一致性 → 镜头自动组合提示词并经生成策略出图/出片 → 评审定版 → 排入时间线产出一条可复现的成片基线;全过程多人按权限协作、有审计、资产与版本可溯源、可回滚。

### 9.1 默认编码规则(D3 落地方案,可在项目级覆盖)

| 实体 | 前缀 | 示例 |
|---|---|---|
| 项目 | 项目短码(建项目时设) | `DEMO` |
| 原著 | `NV` | `NV-001` |
| 剧本 | `SCR`(版本后缀) | `SCR-001`,版本 `SCR-001@v2` |
| 场次 | `SC` | `SC-012` |
| 镜头 | `<场次号>-SH<序号>` | `SC012-SH003` |
| 角色 | `CH` | `CH-007` |
| 道具 | `PR` | `PR-0042` |
| 场景/置景 | `LOC` | `LOC-005` |
| 服化道 | `CO` | `CO-018` |
| 风格模板 | `ST` | `ST-003` |
| 提示词 | `PT` | `PT-021` |
| 生成记录 | `GEN` | `GEN-000128` |
| 基线 | `BL` | `BL-定剪-v1` |

> 前缀、零填充位数可在项目级配置覆盖;序号在项目内单调递增。

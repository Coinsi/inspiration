# 阶段 B1：视频工具验收

日期：2026-09-12。基于阶段 A 的 main `b7afad3`，分支 `codex/video-production-tools`。

## 已交付

- 镜头 / 资产素材卡片以及成片预览下方新增「视频工具」。读取时长、分辨率及音轨信息，支持视频预览。
- 抽取画面：输入 1–12 个不同时间点，或拖动视频后「加入当前画面」，输出独立 PNG。保留源视频 ID、请求时间点和实际图片尺寸。
- 提取音轨：选择起止时间，保存 M4A / AAC，页面可试听、下载；无音轨时明确拒绝。当前取第一个音轨，不做多音轨选择。
- 导出片段：选择至少 0.1 秒的范围，重编码为 H.264 / AAC MP4，保留源视频第一个音轨；无音轨输入保持无音轨。按原视频比例输出，奇数尺寸向下调整为偶数。
- 所有结果复用持久任务、事件、取消 / 重试和素材存储，费用为本地 0 点，源素材保留。成片页新增提取素材列表。声音不能设为镜头画面、资产封面或画面时间线片段。

## 边界与后续

- 工具限制为 30 分钟、256 MB、最长边 8192 像素以内；已有上传入口仍限制 100 MB。实际处理还受本地超时和资源限制，超时进入失败记录。
- 时间点按视频可解码帧选取；AAC、帧率和封装可能带来毫秒级时长差异，不保证任意时间点均有恰好对应的一帧。
- 源音频以 AAC 重编码，不提供无损音频拷贝、多音轨选择、独立音频上传或配音生成。
- 提取自镜头的图片 / 视频仍属于原镜头，可用于它的画面时间线；成片提取素材保存在成片下，可下载，暂未增加跨目标直接转存。
- 真实视频生成仍待供应商名称 / 协议和可用配置。B3 角色预设、视觉提示词以及 C 阶段配音 / 多轨 / 字幕尚未完成。

# 渠道与模型接入改造验收

2026-09-17，批次32。用户明确要求采用影策式多渠道、多模型配置，优先于此前剩余UI项目。未提交、合并或推送。

## 本轮交付

- 新增项目级渠道：显示名称、基础地址、服务端密钥、启停、并发修订号。一个渠道可以添加多个模型；同一模型编号可以经不同渠道配置独立身份与凭据。
- 模型独立配置显示名称、上游编号、协议、图片/视频/文字类型、启停、参考图数量、蒙版能力与参数选项。文字模型可以设为项目默认，接入故事拆解、对象助手、提示词优化与Agent原有调用链。
- 新增兼容 multipart `/videos` 创建、任务查询及 `/content` 下载的异步视频适配，接通现有生成任务及结果回填。每次一个视频，可声明一张起始参考图、时长与画面尺寸。上游取消不是该协议的通用能力，本地停止不保证上游停止计费。
- 设置页改为渠道列表、模型卡片、类型筛选和编辑弹窗；模型目录可读取、可手工填写，不按编号猜测模态或能力。支持明暗与390px布局、键盘焦点、关闭未保存编辑的保护、失败后保留输入。
- 镜头生成与画布显示「渠道 / 模型」；镜头支持声明过的图片尺寸/质量、视频时长/尺寸等参数。画布选择模型同步类型、清除旧参数，Videos模型数量设为1，并保存所选参数。
- 旧配置通过“迁移原配置”一次性归组；保留原provider标识、凭据、适配器参数及旧任务引用。重复迁移不复制配置。迁移前旧接口仍可用；迁移后通过渠道页面编辑，防止旧接口破坏渠道绑定。
- 提交时冻结模型配置，不在任务快照保存密钥；排队期间修改模型编号不会改变该任务的模型。产物保存模型编号。执行时仍检查渠道和模型是否启用，并使用渠道当前凭据。
- 管理操作仅管理员可用；接口不返回密钥。留空保留、更换、明确清除三个行为分开。更新以修订号拒绝并发覆盖，冲突时输入保留、目录刷新，重新打开后读取新版本。新建请求有稳定请求标识，可安全重试。
- 新渠道文字配置缺失凭据/地址，或所有已配置渠道文字模型停用时，明确失败，不退回系统环境密钥。显式选择离线Mock仍可使用。

## 已支持的协议与边界

| 协议 | 状态 |
| --- | --- |
| OpenAI Images兼容 | 复用原生图/参考图/蒙版适配；多个独立模型可共用渠道 |
| OpenAI Chat兼容 | 复用原文字引擎；可配置多个模型及项目默认 |
| OpenAI Videos兼容 | 本轮新增；实际本地HTTP服务验证提交、查询、下载和可播放结果 |
| 旧版自定义 `/submit`、`/status` | 保留原jimeng适配器身份并传递模型编号；明确标注不是火山即梦官方签名协议 |
| 离线Mock | 流程测试，不代表真实模型质量 |

原生Gemini、MiniMax、火山方舟/即梦签名协议等仍需分别适配、配置凭据并实测；不因支持兼容接口便宣称已接通所有厂商。目录读取成功只证明目录接口可访问。视频价格当前未配置，实际费用以上游账单为准；内部配额不等于供应商账户余额。新渠道仍沿用既有密钥存储机制，生产环境须配置原有Fernet加密密钥。

渠道和模型以停用保留历史，本轮不做物理删除、跨项目共享渠道、自动故障转移或原生供应商计费同步。参考影策的渠道与模型分层及协议适配结构，没有复制其数据库和整套实现。

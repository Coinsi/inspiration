## 当前配图

两张 WebP 均截自本地运行的工作台。浏览器使用隔离的演示数据渲染《雨夜归途》的对话和时间线，画面取自仓库自带的[三帧氛围图](../../frontend/public/images/studio-scenes.webp)。对话文案和镜头编排用于演示操作，截图无需调用模型供应商。

| 图片 | 复现画面 |
| --- | --- |
| [创作对话](creative-conversation.webp) | 打开「短片工作室」的创作对话「为开场找一种光」，关联作品《雨夜归途》。用浅色主题展示三种光线与开场建议。 |
| [剪辑成片](film-editing.webp) | 在同一部作品的工作时间线上依次放入「雨夜街头」「旧巷回声」「天光将明」，片长分别为 5、4、3 秒。使用深色主题，选中第一段，显示预览、属性和时间线。 |

更新配图时，使用可公开展示的专用项目和自有素材，检查画面中是否出现真实账号、密钥或私人对话。等待媒体与字体加载，再截取页面。将图片放在本目录，从仓库首页检查桌面和窄屏下的显示与原图链接。

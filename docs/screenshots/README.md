## 更新约定

1. 使用当前版本和专用演示数据，等待图片加载完成；不要截加载骨架、报错或浏览器工具栏。
2. 同一组截图保持相同视口，优先展示能看懂实际操作的内容，避免缩成看不清的拼图。
3. 保持这里的文件名，即可更新 README；改名时同步检查文档链接。图片存仓库中，不依赖临时地址或登录链接。
4. 同时检查浅色和深色 Markdown 预览，确认标题、折叠区和原尺寸图片可读。

`story-bible.png` 与 `storyboard.png` 是此前的历史截图，当前首页不再引用。保留它们供旧版本资料查阅。

# 媒体制作功能与验收

日期：2026-09-12。承接 UI 改造后的功能补齐；本次包含前后端实现，未提交、未推送。

本文保留首轮本地 / Mock 验收范围。后续已完成真实图片服务与真实素材页面验收，最新结论见 [真实服务验收](10-真实服务验收.md)。

## 从哪里开始

1. 打开镜头详情的「生成出图」，或资产详情的生成区。可生成素材，也可上传不超过 100 MB 的图片 / MP4。
2. 图片卡片点「精修图片」：拖选或输入裁剪范围，设置旋转、亮度、对比度和尺寸倍率，保存为新版本。原始素材保留，选中的新版本可钦定用于后续制作。
3. 视频生成区按供应商能力显示时长、比例、清晰度、首尾帧。生成区可单独填写本次指令。支持图生图的供应商可选已有图片作为 AI 重绘参考。
4. 侧栏「任务中心」查看状态、事件、原始输入、失败原因，取消或重试任务。可回到关联镜头、资产或时间线。
5. 「成片 / 基线」创建时间线，添加镜头，选择具体图片 / 视频版本，调整顺序、入点和使用时长，保存并导出。完成后可播放、拖动进度、下载 MP4，并切换历史导出。

## 本次实际支持范围

| 功能 | 实现与限制 |
| --- | --- |
| 图片精修 | 本地裁剪、90° 倍数旋转、亮度 / 对比度、0.5× / 1× / 2× / 4× 尺寸。尺寸放大为插值，不宣称 AI 超分。输出 PNG。 |
| AI 图片重绘 | 已有图片作为参考，沿用已接入供应商的图片编辑接口；没有新增蒙版局部重绘。 |
| 视频控制 | 服务端能力约束与前端选项一致。不支持的字段禁用，后端拒绝不支持的值。首尾帧按角色独立映射。 |
| Mock | 生成明确标记的测试图片和真实可解码 MP4；不根据提示词创作画面。视频支持 3 / 5 / 10 秒，16:9 / 9:16 / 1:1，720p。记录的是测试点数。 |
| 即梦适配器 | 仍是 `/submit`、`/status` 的兼容网关协议，不能直接当作火山引擎官方签名 API 使用。配置须声明 `config.param_schema` 中各字段的 `enum`；首尾帧须在 `config.features` 中声明。未配置或不支持时不显示为可用。 |
| 任务执行 | 持久化任务记录与事件；本地后台线程或 Celery；原始输入冻结；失败 / 取消可重试为新任务，保留原记录；同一任务重复执行不会重复保存输出。 |
| 取消 | 停止本地处理或接收结果。云端已收到的请求不保证可撤销，可能仍然计费；重试云端请求可能再次计费。 |
| 成片导出 | FFmpeg 合成 H.264 / AAC MP4，24 fps，720 / 1080 短边，支持三种比例；直切、图片停留、视频截取、原音轨保留或静音，短素材不足时长保持末帧。最多 100 段、总长 30 分钟。 |
| 基线 | 保存所用素材版本、片段顺序、入出点和时长；同一镜头多次使用保存为多次出现记录。已定剪的 cut 不能重复冻结。 |

不包含自由画布、蒙版绘画、AI 超分、视频延长、多轨配音 / 配乐 / 字幕、复杂转场、3D 导演视图。本次完成的是上述四条制作流程的可用首版，并非与参考产品全部功能等量。

## 运行条件

- 安装后端项目依赖，新增 `pillow`、`imageio-ffmpeg`。FFmpeg 默认使用该包提供的二进制；可通过 `FFMPEG_BINARY` 指定兼容可执行文件。
- 单进程开发：`GENERATION_EXECUTOR=local`、`CELERY_EAGER=false`。后台并发 2 个任务，无需 Redis。本地执行器仅支持一个 API 进程；重启后继续排队任务，将执行中断的任务标为失败以便人工重试。
- 多进程生产：`GENERATION_EXECUTOR=celery`，正常启动 Redis 和 Celery worker。生成任务模块已加入 worker 导入列表；发送队列失败会留下可重试的失败记录。
- 本地文件存储：`STORAGE_BACKEND=fs`，`FS_STORAGE_DIR` 指向持久目录。已有 MinIO 对象仍按原存储路径读取，不能凭空恢复缺失文件；重新上传相同内容可修复不可读旧对象的本地副本。
- 5186 预览使用本地后台执行与本地文件写入。后续验收已恢复原 MinIO 容器，8 张真实图片恢复可读，部分旧原文件仍缺失。没有修改主项目 `.env` 或用户已有镜头 / 资产记录。
- 首轮未发起收费云端请求；后续真实验收发起了 2 次图片请求，详见最新记录。真实视频服务仍未配置，不能宣称已验证官方即梦直连。

## 数据与接口约束

- 图片处理、输入参考图、时间线素材、任务查询 / 取消 / 重试均校验项目归属；时间线素材须属于对应镜头。
- 媒体下载校验文件在项目内的实际引用，支持 HTTP Range；失败文件不会下载成伪 MP4。
- 生成提交与重试计入排队任务预留点数，成功记账使用原子累加；本地免费处理不依赖生成配额。
- 同一个失败任务已有未结束或成功的重试任务时，拒绝再次重复提交。取消后的迟到结果不会写入变体。
- 导出使用提交时的不可变片段快照，之后修改时间线不会改变历史导出。
- 解码只允许本地文件协议；FFmpeg 子进程有超时和取消处理。

主要新增 API：`GET /jobs`，`POST /jobs/{id}/cancel`、`/retry`，`GET /providers/{name}/capabilities`，`POST /generations/{id}/refine`，`POST /media/{shot|asset}/{id}/upload`，`POST /timelines/{id}/render`。均在 `/api/v1/projects/{project_id}` 下。

## 验收

- 后端 15 项自动化测试通过，覆盖：真实像素裁剪 / 旋转 / 尺寸 / 透明度、图片与有音轨视频混合合成、取消、上传→精修→选片→导出、Range / 下载响应、跨项目素材和任务隔离、字段限制、配额预留、队列断开、角色权限、重试幂等、重复执行、迟到结果、重启恢复、网关首尾帧字段映射、重复镜头定剪。
- 数据库集成测试通过随机独立 schema 运行，结束后删除该 schema，使用临时文件目录。设置 `TEST_DATABASE_URL` 后，在 `backend` 运行 `python -m pytest -q`；不设置时只运行不依赖数据库的部分。
- 浏览器实际操作：异步生成测试图片、精修保存并钦定、生成 3 秒 MP4、禁用未支持首帧、片段重排 / 时长、合成 / 播放 / 拖动进度 / 下载、刷新后恢复时间线、任务状态 / 事件 / 输入快照；检查任务、成片、生成页面的 390px 布局。
- 浏览器使用独立测试 schema 与明确标记的测试素材，未把测试数据写入现有用户项目。截图中的 Mock 画面不是实际生成模型效果。
- 前端生产构建与修改后端文件的 Ruff F / I 静态检查通过；原工程前端 lint 脚本仍缺少 ESLint 配置，未将其计为通过。

# 素材引用到创作与字幕衔接

## 已实现

镜头中的固定视频引用可提取中间参考帧、制作视频片段、提取音轨。API 还支持指定范围内的参考帧时间。操作进入已有持久任务记录；请求标识在项目内幂等，镜头锁定与权限校验沿用生成规则。结果作为独立候选保存，不自动采用。

原片、固定版本、引用范围、请求与操作记录保留到结果中；生成面板可返回确切原片版本和时间。参考帧可作为图生图或首尾帧输入，受供应商能力限制；后续生成也保留输入候选和原片来源。视频可进入画面轨，音频含可用时长，可进入声音轨。

处理本地原片时直接定位不可变文件；对象存储通过分块流写到临时磁盘，未使用整片读入内存的接口。尚非对象存储按秒直读或跨机器缓存。每段视频/音轨限60秒，画面适配1920×1080边界，输出限128MB。

活动任务保留原片：任务开始后解除镜头引用仍不能删除原片；取消后可以回收；重试时重新核对原片状态。独立产物保留后允许原片进入回收站，来源记录不因此改指新版本。物理删除仍未开启。

## 字幕衔接

剪辑中的“匹配原片字幕”读取已核对发布的自动转写，按原片范围、剪辑入点、重复使用和转场重叠换算时间。预览匹配数量、未匹配片段和字幕样例后，才能替换当前草稿；可撤销，保存剪辑才写入。匹配时剪辑或字幕变化会阻止应用过期结果。记录原片版本、原字幕、衍生候选与对应原片区间。

只匹配直接从素材库制作的视频片段；再次裁剪、变速等衍生链暂未追溯映射。未发布字幕、图片或其他来源画面明确计为未匹配，不伪造字幕。转场重叠可能产生同时出现的字幕，需要预览核对。

## 验证

- 后端真实FFmpeg测试提取原片蓝色时间段，检查图像像素、视频与音频时长。禁止整片字节读取接口后仍通过。
- 验证重复请求、错误时间、错误项目、锁定镜头、取消、解除引用后保留、回收后拒绝重试；音频可加入时间线并实际导出。
- 模型输入使用受控供应商合同测试，检查实际提取帧被编码并传递，不能把该测试称为云端生成质量验收。
- 字幕测试覆盖两个重复片段、不同入点、200ms转场、未核对/画面标注排除、只读预览与来源保存。
- `frontend/tests/library-materialize-live.mjs` 实际创建三类候选、返回原片、调用本地真实ASR、发布、匹配剪辑字幕、加入提取音轨、保存并导出MP4。附加同源音轨设为静音，成片只播放一次原声。
- 产物 `platform-rebuild-batch12/source-to-cut.mp4` 为约4.12秒、1280×720、24fps，真实解码帧可见正确字幕。测试视频本身是合成语音配纯色画面，不代表影视画面质量。

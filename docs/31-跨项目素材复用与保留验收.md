# 跨项目素材复用与保留

## 批次17范围

在目标项目的视频库选择“从其他项目复用”，搜索来源视频并选择固定版本。操作要求源项目和目标项目均有素材编辑权限。目标项目创建独立的素材、版本记录，直接引用同一组不可变原片、预览、封面文件，不复制上传或重新转码。源素材后续新增版本不会替换目标版本。

复用明确将该版本授予目标项目成员使用，之后源项目成员权限变化不会自动撤销目标项目已经获得的素材。字幕、索引、人物判断与镜头引用各自归属项目，不随视频一起复制。历史来源保留来源版本编号、素材名与版本序号；不会通过目标页面暴露源项目的其他内容。

同一来源版本在同一目标项目仅建立一份复用记录。重试或重复点击返回已有素材；目标素材在回收站时要求恢复，不静默新建或自动恢复。不同源版本可分别复用。

## 删除与权限

原素材删除检查包括各版本的跨项目复用。在目标素材仍正常使用时阻止原素材移入回收站。可访问的目标项目显示定位链接；无权访问或已归档项目只显示匿名依赖，仍纳入保护。

目标项目的镜头引用仍保护其自己的素材。解除镜头引用并移入回收站后释放这处活动复用依赖。目标素材恢复使用自身固定文件记录，不要求原素材仍在正常列表中。

项目锁按固定顺序获取，源素材锁与删除串行。复用先成功时删除被拒绝；删除先成功时复用被拒绝。锁定素材时重新读取数据库状态，避免使用旧缓存判断。两边均记录操作审计。

## 验证

- 隔离数据库真实视频测试：不同版本ID、相同原片/预览哈希；禁止调用文件写入，Blob数量不增加；目标项目Range读取与原始字节一致；固定版本不跟随更新。
- 权限与保留测试：错误来源、只读角色、无成员权限被拒绝；无权访问的目标名称不泄漏；两侧引用保护、回收、恢复通过。
- 并发测试：复用/删除两个执行顺序，以及两个同时首次复用请求只创建一份目标记录。
- 新装、升级、降级、再次升级通过；只迁移隔离预览schema到0015，未修改主项目数据库。
- `library-reuse-live.mjs` 新建两个QA项目，真实上传、浏览器复用并解码预览、引用到镜头、查看跨项目删除影响、解除后回收/恢复、重复导入与390px明暗布局通过。证据目录 `platform-rebuild-batch17`。

## 仍未覆盖

本批没有物理删除共享文件，也未实现整个项目资源关系图、撤销已经授予目标项目的素材、批量跨项目复用，或字幕/向量索引跨项目共享。未来物理回收必须同时考虑所有版本、回收站、衍生产物与任务保留，不能仅按本项目的活动引用计数删除文件。

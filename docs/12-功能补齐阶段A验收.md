# 功能补齐阶段 A 验收

日期：2026-09-12。对应 [功能对照与计划](11-影策功能对照与补齐计划.md)。本批交付局部重绘、提示词优化首版及剪辑基础编辑；不代表影策全部功能已经补齐。

## 使用入口与支持范围

- 资产或镜头的生成面板：选择 GPT Image 后，在图片卡片点击「局部重绘」。画笔涂选、擦除、撤销 / 重做、调整笔刷、填写修改要求，查看预估点数后提交一张新版本。Mock / 未声明支持蒙版的供应商禁用此入口；GPT 网关可通过 `config.mask_editing=false` 关闭。
- 生成面板「优化提示词」：填写想法，选择精修表达、扩展想法或强化风格。使用项目已启用的文本模型，输出完整提示词、建议规避项、修改说明和新增假设；结果可编辑，点击采用只回填优化后的提示词，不自动生成媒体。规避项为单独展示的建议。
- 成片 / 基线：每段支持复制、按片段内时间拆分；拆分后第二段入点自动增加、总时长保持。最近 100 步编辑支持撤销重做，保存不清空历史。离开编辑会话后历史不保留，已保存片段支持刷新恢复。

## 实测结果

| 检查 | 结果 |
| --- | --- |
| 独立蒙版 | 请求中 `image[]` 和 `mask` 为不同文件；透明区域是修改区域，蒙版尺寸与原图一致 |
| 服务端输入 | 限制图片尺寸、点数和笔画数；拒绝空选区、非法坐标、不支持供应商、跨项目图片；只读角色不能调用 |
| 真实局部重绘 | 通过实际浏览器提交一次 gpt-image-2 图片编辑请求，约 31 秒返回 1536×1024 PNG，应用记录 30 点；保留来源图片 ID、蒙版哈希与任务事件 |
| 真实画面质量 | 红色茶壶旋钮改蓝，壶身和壶盖保持红色；但旋钮变大且更圆，不能声称“只改颜色且保持形状”通过 |
| 选区外保持 | 原图与结果选区外 RGB 平均绝对像素差约 2.55 / 2.94 / 2.58（0–255）；不是像素级无变化。当前是模型引导的局部编辑，不做选区外强制像素合成 |
| 真实提示词优化 | 一次现有文本模型调用返回有效 JSON；保留茶壶、红色、灰背景及无文字要求；页面可预览、编辑并采用 |
| 片段拆分 | 3 秒源视频取入点 0.2 秒、时长 2.4 秒，在第 1 秒拆分为入点 0.2 / 1.2 秒、时长 1 / 1.4 秒，顺序与总时长正确 |
| 历史与保存 | 复制→撤销→重做→撤销、保存后撤销 / 重做、回到保存状态时保存按钮禁用；刷新后片段值一致 |
| 导出与播放 | 上述两段实际导出 MP4；浏览器加载、播放、下载通过，时长约 2.4 秒 |
| 移动端 | 390px 下局部重绘、提示词面板、剪辑拆分操作可用，无页面横向溢出；浏览器无运行时错误 |

测试使用随机独立数据库 schema 和临时存储，复制现有供应商配置用于调用；用户项目素材与配置未被测试改写。云端只调用一次图片编辑、一次文本优化。30 点是应用记录，不等于供应商货币账单。

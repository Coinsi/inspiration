# 00 · 术语表(Glossary)

> 本表统一全项目核心概念,所有需求/设计文档引用此处定义。修改术语须同步更新本表。

## 一、领域实体术语

| 术语 | 英文 | 定义 |
|---|---|---|
| 原著 / IP | Novel / IP | 项目的内容源头,小说或原创设定,可含多章节。支持多格式导入。 |
| 大纲 | Outline | 故事梗概/分集大纲,介于原著与剧本之间的叙事资产。 |
| 剧本 | Script | 由大纲改编的可拍摄文本,含多版本;由若干场次组成。 |
| 场次 / 场 | Scene | 剧本的基本叙事单元,可溯源到原著章节;由若干镜头组成。 |
| 镜头 | Shot | **系统的核心生产单元**。向上隶属场次(拆解),向下产出视频片段并排入时间线(组装)。编号如 `SC012-SH003`。 |
| 资产 | Asset | 可被镜头引用、可复用的实体。分蓝图类与产出类(见下)。 |
| 蓝图类资产 | Blueprint Asset | 可复用的"配方"型资产:角色、道具、场景/置景、服化道、风格模板、提示词、模型/LoRA。 |
| 产出类资产 | Output Asset | 生成产生的具体产物:概念图、分镜图、视频片段。 |
| 角色 | Character | 蓝图资产,含视觉身份(参考图集 / LoRA / 提示词片段 / 三视图)。 |
| 提示词 | Prompt | 一等资产,可版本化、可拆分为可复用片段、可被组合。 |
| 时间线 / 序列 | Timeline / Sequence | 镜头片段按顺序、入出点、转场组装成的成片骨架。 |
| 成片 | Film / Cut | 项目最终交付物(电影/动漫),其版本即整片基线(粗剪/精剪/定剪)。 |

## 二、版本与配置管理术语

| 术语 | 英文 | 定义 |
|---|---|---|
| 修订 | Revision | 同一实体的**串行**改进,有取代关系(如剧本第一稿→第二稿)。 |
| 变体 | Variant | **并行**的多个备选,均合法,择其一(如一次生成的 50 张图)。 |
| 基线 | Baseline | 某一刻**整体配置**的命名快照,冻结一整套实体及其版本,保证可复现。 |
| 浮动引用 | Floating Ref | 引用永远跟随被引实体的最新版本。 |
| 钉死引用 | Pinned Ref | 引用锁定到被引实体的某一具体版本。 |
| 溯源记录 | Provenance | 不可变的"出生证明",记录某产物由哪个提示词版本/模型/参数/参考图生成。 |
| 内容寻址存储 | CAS | 二进制按内容哈希存储一份并去重,版本仅存指针。 |

## 三、生成与策略术语

| 术语 | 英文 | 定义 |
|---|---|---|
| 生成供应商 | Generation Provider | 一种生成引擎的策略实现(如 ComfyUI、Midjourney、Runway、可灵)。 |
| 能力声明 | Capabilities | 供应商声明自身支持的模态与特性(图/视频、img2img、参考图数、视频时长等)。 |
| 生成任务 | Generation Job | 一次异步生成的生命周期实体(pending→running→succeeded/failed)。 |
| 生成 | Generation | 一次生成的溯源记录(冻结输入 + 产出)。 |
| 一致性策略 | Consistency Strategy | 实现角色/画风一致性的可切换方案(纯提示词 / 参考图 / LoRA)。 |
| 解析策略 | Novel Parser | 将任意格式小说转为统一结构化文档的策略(txt/docx/epub/pdf...)。 |
| 策略注册中心 | Provider Registry | 各类策略自注册、按能力匹配选用的基础设施。 |

## 四、协作与流程术语

| 术语 | 英文 | 定义 |
|---|---|---|
| 项目 | Project | 权限与数据的隔离边界,对应一部成片。 |
| 角色 | Role | 工种角色(管理员/导演/编剧/美术/制片/访客),决定权限。 |
| 评审 | Review | 对产出资产的审批流程,含批注、闸门、返修轮次。 |
| 返修 | Revise / Retake | 评审打回后带意见的重做。 |
| 制作状态 | Production Status | 镜头级流水线状态(待设计→概念图→生成中→待审→返修→定版→已入剪)。 |
| 配额 | Quota | 项目/用户的生成成本或算力上限。 |

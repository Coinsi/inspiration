# Inspiration —— 影视/动漫 AIGC 资产管理与生产平台

> 项目代号:**Inspiration**
> 一句话定位:以"资产管理 + 配置管理"思想为内核,贯通 **小说 → 大纲 → 剧本 → 场次 → 镜头 → 资产 → 生成 → 成片** 全流程的 AIGC 影视/动漫生产平台。

---

## 一、产品核心理念(四条主线)

整个系统由四条贯穿始终的主线支撑,所有设计决策都围绕它们展开:

1. **依赖图(Dependency Graph)** —— 一切实体都是资产节点,通过"改编 / 组成 / 引用 / 复用"关系连成有向图;支持正向拆解与反向溯源。
2. **可插拔策略(Pluggable Strategy)** —— 所有易变的外部能力(生成引擎、小说解析、AI 拆解、导出等)统一抽象为可注册、可替换的策略,遵循开闭原则。
3. **多人权限(Multi-tenant RBAC)** —— 以"项目"为隔离边界,按工种角色授权,关键操作(锁定、定稿、触发生成)受权限与审计约束。
4. **多版本配置管理(Versioning & Configuration Management)** —— 区分修订 / 变体 / 基线;引用支持浮动与钉死;生成溯源不可变;整片以基线形式冻结可复现。

## 二、业务总闭环

```
┌── 自顶向下拆解(创作期)─────────────────────────────┐
原著 → 大纲 → 剧本 → 场次 → 镜头
                              │
                    镜头为核心独立生产:
                    概念图 → 生成视频片段 → 评审 → 定版
                              │
└── 自底向上组装(后期/成片)───────────────────────────┘
镜头片段 → 时间线排序 → 序列 → 剪辑(粗剪→精剪→定剪) → 成片(电影/动漫)
```

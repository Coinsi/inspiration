# 素材处理与检索使用指南

在项目侧栏打开“素材库”，进入“项目素材”。视频、图片和音频都在这里管理。AI生成作品还有独立的“AI生成”入口；归入素材库后，使用同一套版本与引用关系。

## 导入并准备素材

1. 点击“导入素材”，选择本地文件，再点击“开始 / 继续上传”。视频支持MP4、MOV、MKV、WebM；静态图片支持JPEG、PNG、WebP；音频支持MP3、WAV、M4A、FLAC、OGG。实际文件还需通过解码校验，扩展名被支持不代表所有编码组合都已验过。
2. 上传完成后，后台保留原文件并另行生成预览。上传、预览完成、字幕完成和检索索引完成是不同状态，能播放预览不代表已经可以搜索内容。
3. 从素材卡片打开“处理与检索”，选择需要的能力；“素材处理”页可查看项目中的任务。只有部署就绪的能力可以使用。

| 想做什么 | 处理能力 | 适用素材 |
| --- | --- | --- |
| 描述画面、用图片寻找相似画面 | WISE画面索引 | 图片、视频 |
| 描述声音、用一段音频寻找相似声音 | WISE声音索引 | 音频、带音轨的视频 |
| 制作兼容预览、转码 | MediaCMS预览 | 音频、视频 |
| 从语音生成有时间段的字幕 | MediaCMS字幕转写 | 有语音的音频、视频 |
| 用描述或参考区域寻找物体 | 物体区域索引（可选） | 图片、视频 |

管理员启用自动处理后，上传变为可使用状态的素材会按类型排队处理；默认自动策略只选择基础画面/声音能力和已启用的MediaCMS能力。启用物体模型不会自动为整个库追加物体索引。自动队列也不会把已经取消或失败的任务悄悄重跑，需要手动重试。入库会实际检测音轨；确定没有音轨的视频只做画面与预览，声音检索和字幕选项会显示“无音轨”，不会提交必然失败的声音任务。旧素材尚未探测时保留未知状态，不凭文件名猜测。

页面支持暂停上传。重新打开后选择同一个原文件，可校验已上传分块并继续；同名的不同文件不能冒充原文件续传。默认视频/音频单文件上限为10 GiB、时长上限6小时，静态图片上限64 MiB；实际限制以部署配置和服务返回为准。素材处理还受独立的磁盘与队列预算限制。

## 搜索需要的内容

打开“搜索素材”，按问题选择检索方式：

| 检索入口 | 适合的问题 | 结果含义 |
| --- | --- | --- |
| 字幕与标注 | “哪一段说了这句台词？” | 按输入文字查找字幕或人工标注，不需要视觉模型 |
| WISE画面 | “找雨中的街道”、上传参考图片 | 返回相似图片或视频抽样画面 |
| WISE声音 | “找雨声”、上传参考音频 | 返回声音相似的候选时间段 |
| 物体区域 | “找杯子”、在参考图中框选杯子 | 返回候选物体框及其所在图片/采样时刻 |

字幕搜索会查自动转写、导入字幕和人工标注。输入“白色的小鸟”只会命中包含这段连续文字的标注；说到小鸟不代表画面里出现了小鸟。转写可能出现同音字错误。当前可在素材详情展开“为所选片段添加检索标注”，按时间范围保存正确的“台词内容”，并移除错误标注；也可导入校对后的字幕。现有独立字幕页面尚未接通 MediaCMS 的整份自动字幕校对，统一校对入口仍待补齐。单字或极常见词可能命中很多内容，增加几个字通常更有用。

内容检索需要对应版本完成相应索引。页面会显示索引覆盖范围，未处理素材不会参加该类搜索。文字、参考图和参考音频每次选择一种查询输入。物体参考图可以拖动框选或输入百分比坐标；换图后重新选择区域。

语义分数用于候选排序，不是正确率或身份概率。当前WISE视频画面每秒抽样2帧，可能漏过短暂动作；结果时间是画面定位，不是自动识别出的完整镜头边界。当前最多取100个候选再分页，按版本合并只是整理这些候选，不表示找全了素材里的全部对象。

## 预览并用到创作里

点击结果打开素材详情。图片显示整图；视频和音频定位到匹配位置。对物体结果，可以从“命中区域”列表切换同一素材的其他区域或时刻；视频播放时隐藏位置框，它并不执行连续物体跟踪。

确认内容后调整入点、出点，播放所选片段，再选择目标镜头、用途和备注，点击“引用到镜头”。图片引用整张图。引用固定指向原文件版本：轻量预览只是播放用的派生文件，上传新版本不会改写旧引用。保存引用不会自动加入剪辑时间线，也不会把完整原片发送给生成模型。

## 任务异常时

| 页面提示或现象 | 处理方式 |
| --- | --- |
| 已上传但搜索不到 | 查看对应能力是否处理完成，并核对搜索覆盖范围 |
| 排队或处理中 | 查看“素材处理”；重任务受到并发限制，排队不等于失败 |
| 索引正在处理其他任务 | 稍后重试内容搜索；当前本机配置将WISE索引与查询串行执行 |
| 可选模型尚未验收 | 由管理员核对服务状态；只填写地址或打开开关不能代替准备模型 |
| 模型更新后需要重建索引 | 在“处理与检索”中重新建立对应索引，不能继续使用不兼容的旧特征 |
| 任务取消或失败 | 原片与已存在的合法引用保留；确认原因后手动重试 |

素材移入回收站后不再参与新的搜索，外部服务的临时副本和索引通过后台任务清理。恢复素材后，旧删除任务不会被直接忽略；需要按页面状态重新处理，恢复可检索能力。

本机已验证的格式、时长、模型和负载范围详见[集成验收记录](70-素材检索与处理集成计划.md)。可选模型边界见[人脸与物体检索说明](71-可选人脸与物体检索验收边界.md)，部署方法见[服务部署指南](../deploy/media-services/README.md)。

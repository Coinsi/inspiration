# 素材目录与工作区界面打磨

这是一轮已打通流程的界面优化，不代表全站视觉改造或全部路线图完成。

## 功能与布局

- 视频目录按24项分页，名称查询和最近/最早/名称排序在服务端执行；版本与引用统计只查询当前页。单条详情独立读取，检索或生成结果可以打开列表页外的原片版本。
- 网格与列表可切换并保留偏好；封面可直接点击预览，时长覆盖显示，上传中/失败/空结果区别展示。
- 侧栏分组可收起并保留偏好，进入对应页面会展开所在分组；紧凑导航减少滚动，快速导航仍包含所有20个目的地。
- 镜头工作区加宽并可展开；已选画面显示在卡片和详情中，未选候选不冒充定稿。窄屏进入镜头时隐藏后方看板与统计，直接展示详情，提供返回入口。
- 镜头请求失败不再显示零进度；快速切换镜头时忽略旧提示词请求结果；项目切换重置局部工作区，生成后选定画面可刷新。

参考影策工作区与导演台控件分层：浏览视图切换不修改创作内容，媒体预览与编辑面板分别组织；复用本项目原有业务与主题。

## 验证

后端55条目录跨3页测试无遗漏/重复，名称中的百分号和下划线按普通字符查询，跨项目详情拒绝读取，分页大小有界。

`workspace-polish-live.mjs` 在真实预览项目检查名称查询、排序、空结果、偏好恢复、分组收起、原片详情、展开镜头工作区及390px布局。明暗主题、列表/网格、移动详情截图已检查；浏览器无页面异常。公开样本项目有4条记录，其中1条未完成上传，真实状态保留。

原有素材上传、检索与工作区回归脚本均通过：中断续传、错误区别空数据、精确片段定位、章节范围隔离、快速导航键盘/焦点、窄屏导航和英文入口。旧导航测试的14项目的地计数更新为当前20项。

证据在 `platform-rebuild-batch13`。此次检查时后端83项全部通过；之后故事流程专项见文档29。前端构建通过，导演台独立加载包仍有体积提示。

## 后续边界

全站尚需继续统一生成面板、画布、导演台、技能表单、故事设定和任务诊断的视觉与交互。旧版素材选择器仍可能一次读取全部目录，当前分页改造仅覆盖主目录。未提供目录层级、批量整理、跨项目复用或物理清理。

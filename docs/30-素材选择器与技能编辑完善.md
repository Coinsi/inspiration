# 素材选择器与技能编辑完善

## 批次15：大量素材下的选择与固定版本

转写页、身份与证据页不再读取整个视频库。新增按可用视频版本分页的查询：每页24条，上限100条；即使一项素材有很多历史版本，也按版本数限制响应。名称匹配按字面处理百分号与下划线，查询排除回收素材、处理中版本和其他项目。

两个页面共用版本选择器，提供名称搜索、翻页、当前版本封面与时长、加载/失败/重试/无结果状态。选中版本独立读取：翻页或搜索不清空选择，不自动改成最新版本；从素材详情进入时可读取当前页以外的固定版本。所选原片读取失败时不能开始新转写，也不能用未知时长创建证据。

`test_library_catalog.py` 在隔离数据库中验证55项素材以及同一素材55个可用版本的三页查询、固定版本读取、回收与项目权限、字面搜索和最大页长。

`library-picker-regression.mjs` 先读取真实预览项目的原片、目录和已有字幕，再用受控51版本响应验证跨页保留、迟到响应、失败重试与空结果。浏览器实际检查390px布局以及两个页面不再发起全库请求；不将受控响应描述为真实大库性能测试。证据在 `platform-rebuild-batch15`。

## 批次16：技能草稿与输入稳定性

技能草稿按用户和项目保存在本机；刷新自动恢复未保存内容并显示提示，保存成功后清理本机草稿。切换技能或载入服务器版本前提示替换草稿，归档操作要求先处理未保存修改。保存仍使用服务端原有版本冲突校验，新增精确技能读取接口也校验项目权限。

保存、Markdown读取和历史恢复期间锁定编辑输入与对象切换，防止迟到响应覆盖另一份编辑内容。列表加载失败单独显示重试，避免误称没有技能。手机界面改为选择/编辑切换，编辑正文不再排在模板列表后；桌面保留左右工作区。

外部目录读取与提交期间锁定文件和来源输入；切换页签保留目录预览与进行中的提交。非法摘要/标签等对象类型在预览前拒绝，避免直接渲染非文本数据导致页面崩溃。

`skills-live.mjs` 验证真实接口创建、版本更新、历史恢复、目录资产导入与Agent选择。`skill-draft-regression.mjs` 创建专用QA项目，实际验证取消切换、刷新恢复、另一写入者造成409且两份内容保留、明确载入后保存、手机编辑布局。另以受控延迟验证保存与文件读取期间禁用输入，并实际提交有效目录。证据在 `platform-rebuild-batch16`。

## 边界

这两批没有实现跨项目素材共享、物理文件清理、分层文件夹或自动角色识别；主素材详情仍可读取单个素材的全部历史版本，资产/角色的旧选择器也需继续专项审计。技能本机草稿每个用户、项目保留当前一份，未实现跨设备草稿同步或三方合并；外部目录预览没有持久化到服务器。新建技能的网络响应丢失幂等恢复仍需完善。

验收结果：批次14结束时完整后端85项通过；这两批修改后的目录与技能专项6项通过，两个新增浏览器回归与原有技能真实接口流程通过，最终前端生产构建通过。针对修改文件的静态检查通过（沿用FastAPI依赖参数的B008例外）；导演台独立资源包仍有大于500KB的构建提示。

所有改动保留在工作区，未提交代码。

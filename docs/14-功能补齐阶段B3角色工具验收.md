# 阶段 B3a：角色工具首版验收

日期：2026-09-12。基线 main `1be13c8`，分支 `codex/character-production-tools`。

## 已交付

- 在镜头和资产的图片卡片上新增「角色工具」。选择支持参考图编辑的图片供应商后可用；Mock 不具备该能力，入口禁用且后台拒绝直接调用。
- 角色视角：正面、四分之三侧面、朝左侧面、朝右侧面、背面。左右按鼻尖在画面中的朝向定义。
- 角色表情：平静、微笑、悲伤、生气、惊讶、严肃。
- 三视图：一次生成一张包含正面、朝左侧面、背面的全身角色参考板；不是三张独立图片，也不是 3D 模型。
- 可填补充要求，先预览完整生成要求和预估点数，再明确点击生成。修改分类、预设或补充要求后，旧预览失效，需重新预览。
- 每次生成 1 张，保留原图，不自动钦定。任务保存预设版本、分类、名称、补充要求、参考图哈希和来源素材 ID；失败重试沿用任务中已保存的提示词和预设。
- 结果卡片显示预设名称与来源 ID，已有任务状态、尺寸差异提示和下载能力继续适用。

## 实测结果

测试使用隔离项目，读取用户项目已有角色拼图，通过现有图片精修功能裁出一个人物作为参考。用户项目素材与配置未被测试改写。复用已配置的 gpt-image-2 服务，正面、微笑、三视图各提交一次真实图片编辑请求，共 3 次，应用记录 90 点；点数不是供应商货币账单。

| 验收项 | 结果 |
| --- | --- |
| 正面视角 | 原侧向人物转为正面平视；黑色长发、深色服装、银色饰品等主要特征可辨认。部分五官、服饰纹样和饰品位置重绘，不保证严格一致 |
| 微笑表情 | 嘴角上扬，形成自然微笑；整体视角、发型和服装相近。并非只改变面部像素，服装与背景仍有变化 |
| 三视图 | 单张 1536×1024 横图，恰好正面 / 朝左侧面 / 背面三个人物视图，完整全身、灰色背景、无遮挡和文字。未在原图出现的腰部、衣摆和背面配饰由模型推演 |
| 参考图传输 | 协议测试确认请求走 `/images/edits`，multipart 包含真实参考图字节；生成提示词与预览一致，未用纯文字替代参考图 |
| 尺寸差异 | 正面和微笑请求 1024×1024，网关实际返回 1254×1254；现有校验产生可见警告。三视图请求和返回均为 1536×1024 |
| 预览不生成 | 12 个预设均经过无生成调用的预览测试；浏览器修改要求后不能沿用旧预览提交。浏览器补充验收没有额外调用生成服务 |
| 保存与恢复 | 三类结果回存原镜头，来源 ID 与预设正确，重新打开后仍可查看；失败任务重试保留原始输入 |
| 权限与失败 | 非图片、跨项目来源、错误分类 / 预设组合、超长补充要求、只读角色和点数不足被拒绝；预览错误保留用户输入，可重新预览 |
| 页面与手机 | 390px 无横向溢出，滚动后可操作提交按钮；补全控件可访问名称，浏览器无运行时错误 |

三项真实请求验证了基本创作效果，不能据此推断所有角色、画风和 12 个预设都能稳定保持身份。其余预设完成协议和预览检查，未各自追加收费质量验证。参考图中残留的拼图边缘在部分输出中被保留，使用时应先裁净边缘。

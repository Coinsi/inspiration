# 项目创建与封面（批次25）

日期：2026-09-16。用户指出项目创建必须填写编码、无法添加封面不符合创作习惯。本轮移除创建流程中的内部编号负担，并补齐封面管理。未提交代码。

- 创建弹窗只要求项目名称，简介和封面可选；服务端生成唯一项目编码。旧 API 的手动编码仍兼容，已有项目编码和引用关系不变。
- 创建时选择/拖入封面，展示 16:9 预览；项目卡片展示封面，有“添加封面/更换封面”入口。可以移除封面恢复文字占位。
- 支持 10 MB 内的静态 JPEG、PNG、WebP，服务器实际解码验证，最多4000万像素。保存原始上传文件，不重新压缩；卡片通过视觉裁切展示。
- 创建项目和封面在同一次事务完成。新建请求具有稳定请求键，并发或响应丢失后的重试只返回同一项目；错误图片不会留下空项目。
- 封面使用现有文件存储和项目成员鉴权，不接受任意外部素材哈希来绕过所属关系。只有项目管理员可更改封面；移除/替换只修改封面引用，不物理删除可能被其他业务使用的文件。
- 首页不再展示内部项目编码，但保留兼容搜索；项目名称、描述、进入工作台等原有功能保留。

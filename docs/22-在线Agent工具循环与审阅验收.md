# 在线 Agent 工具循环与审阅验收

日期：2026-09-15。隔离预览验证，未提交代码。

## 交付流程

创作助理页面可创建项目任务，填写目标，选定允许提出修改的镜头、角色/资产和剧本。未授权对象仍可按项目成员权限读取，但不能提出修改。工具目录与模型分离，当前工具涵盖项目概况、对象读取、最小编辑提议、视频片段检索、画布读取、生成任务读取与图片/视频生成申请。

每轮模型只选择一个动作，后台执行后持久保存结果，再把真实结果送入下一轮。文本修改生成前后对比，批准时加锁并比较提议时的原始内容摘要；对象已被别人修改则拒绝覆盖。批准和版本写入、步骤状态在同一事务完成，重复批准不重复修改。媒体生成也先显示预计费用，批准时重新核对费用与权限；任务关联与派发原子衔接，后续模型读取实际结果，不自动采用候选。

支持刷新恢复审阅、暂停、继续、取消和执行轮数上限。模型调用中断后暂停，避免后台默默重复计费请求；取消后迟到的模型回复被丢弃。工具目录拒绝未知动作，技能或模型不能扩大用户给定的修改范围。所有 API 数据库依赖均在响应前提交事务。

## 验证证据

- 新增6项Agent后台场景通过：实际对象读写与反馈、重复批准、旧提议冲突、越权范围、未知工具、循环步数、模型中断、取消后迟到回复、生成审阅与候选溯源、兼容返回解析。
- Agent与画布共11项定向回归通过，完整后端回归在画布阶段63项通过；后续累计检查按实际运行补充。
- **真实 gpt-5.5 浏览器流程通过**：读取授权镜头→提出标题与描述修改→刷新恢复审阅→批准→再次读取实际状态→结束，共4轮，3次工具执行。批准前数据库未改变，批准后标题与描述逐字符合要求，生成不可变版本，无额外图片/视频请求。
- 深色、浅色、390px页面无横向溢出，无浏览器脚本异常；审阅截图已实际检查。
- 供应商偶发把工具JSON和结束说明JSON串在一起。解析只允许相同动作去重或忽略末尾无动作的finish说明，始终执行并审阅前面的工具；遇到两个不同的可执行动作则拒绝。不让提前结束说明跳过实际执行。

证据：本任务输出目录 `platform-rebuild-batch07/report.json`、审阅/结果截图；测试文件 `backend/tests/test_agent.py` 和 `frontend/tests/agent-live.mjs`。真实流程项目为“Agent 验收 · 审阅与恢复”，仅写隔离测试对象。

## 边界与后续

模型层目前是兼容JSON动作协议，非任意代码执行环境。只支持登记工具；默认12轮，单次创建最多24轮，用户追加后的任务总上限96轮。暂未支持逐token流式回复、细粒度模型token计费核算和多任务并行模型调度。视频生成和声音模型质量仍需各供应商独立验收；本批实际验证了文本模型编辑链路，媒体申请用离线供应商验证任务事务与反馈。

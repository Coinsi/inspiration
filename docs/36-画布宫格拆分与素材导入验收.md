# 画布宫格拆分与素材导入（批次22）

日期：2026-09-16。承接批次21，继续以 UI 和创作工具为优先。代码未提交。

## 已实现

- 图片节点上方新增「拆分图片」：原图上实时显示等分线，提供 1×2、2×2、3×3、4×4 预设，行列可分别设置为 1—4，点击格子选择保留内容。
- 服务端按解码后像素边界裁切、输出透明 PNG，不缩放；奇数宽高使用整数边界，完整选择时不遗漏边缘像素。静态图片限制最长边 8192、总计 4000 万像素。
- 分格作为同一资产或镜头的独立版本保存，记录原生成版本、原文件哈希、行列、格子序号、像素裁切框；不更改已采用版本。节点显示分格序号并可查看来源原图。
- 一次拆分在画布中以一次操作加入全部选中格子，保留其宫格位置并避开已有节点；支持整体撤销、重做、保存恢复。撤销节点不会删除已经保存的版本，界面明确说明。
- 同一原图的并发拆分请求串行校验幂等键；已提交但响应丢失时，重试返回原结果，不重复创建版本。设置不同而复用相同键返回冲突。数据库写入失败整体回滚。
- 「项目素材」中选择所属资产或镜头后，可选择或拖入本地图片、MP4，预览后导入并放入画布。支持 PNG、JPG、WebP、MP4，单文件不超过 100 MB；更大视频继续使用现有素材库流程。
- 导入期间锁定对象切换与关闭，显示失败消息并允许重试；成功版本缓存即时刷新。文件上传沿用现有接口，不宣称它具有拆分接口的请求幂等保证。
- 新素材放入后视口聚焦到内容；新增布局避让，不再默认堆叠在同一坐标。拆分工具支持明暗主题和 390px 窄屏，窄屏主操作固定在工具底部。

## 边界与后续

- 当前是规则等分裁切，不是自动识别拼图边框、智能去间隙或自由裁切。
- 本地文件拖放入口在素材选择面板内；需要先有所属资产或镜头，不是任意文件直接落到画布自动建对象。
- 拆分只做本地处理，不调用云端生成模型。引用连线和版本恢复已验收，云端模型的图生图效果没有在本批次验证。
- 画布自由绘图、智能文本引用和更完整的节点编辑器仍未完成；导演台、剪辑的进一步 UI 打磨仍在后续计划。

# 产品官网与内容管理

## 入口与设计

- `/`：公开产品官网，无须登录；已登录用户的创作入口进入工作台，访客进入注册页。
- `/admin/website`：独立平台管理端；右上角账户菜单对平台管理员显示入口，所有用户均可返回产品官网。
- `/login` 和 `/register` 保留现有视频背景，并新增返回官网入口。

参考 https://laper.ai/ 的浅色、绿色字体、大留白、细线网格、产品演示与分段叙事方式。采用 Inspiration 自身品牌、原创中文文案、灯塔插画及虚构故事《最后一盏灯》，没有复制对方商标、用户评价或产品数据。

首页包含首屏、四视图产品交互演示、创作流程、产品能力、创作示例、FAQ 和注册入口。演示中的切换、镜头选择和时间线播放可交互，明确标注为示例，不调用模型、不读取私人项目。适配手机、键盘操作及减少动态效果偏好。官网与工作台路由分包，打开官网不加载画布/三维导演等大型模块。

## 更新官网

1. 使用平台管理员账户进入管理端。
2. 修改品牌、公告、标题、介绍、按钮文字、各功能说明、案例、FAQ 和页脚；调整板块顺序或隐藏板块。
3. 如需更换展示图片或视频，在对应位置选择/上传。支持静态 JPG、PNG、WebP 和 MP4，每个文件最大80 MB；不会重新压缩上传的素材。
4. 预览草稿可直接看到尚未保存的本地编辑。保存草稿只更新后台，不改变访客看到的内容。
5. 填写发布说明并确认发布。发布成功后，新请求读取新版本。
6. 在发布历史中恢复旧版本会先覆盖草稿，须再发布才影响官网。

普通内容和媒体更新不需要重新部署代码。固定演示中的剧情、交互逻辑、四种创作流程标签，以及页面结构/布局仍由代码维护；当前不是任意拖拽搭建页面的编辑器。

## 管理员配置

平台管理员与项目角色独立；项目管理员不能修改官网。没有默认管理员，公开 demo 账号不会自动获得此权限。先注册实际管理者账户，再在 `backend` 目录使用服务端环境执行：

```powershell
python -m app.modules.website.admin grant <已注册用户名>
python -m app.modules.website.admin revoke <已注册用户名>
```

授权/撤销均读取数据库当前身份，撤销后旧 JWT 也不能继续管理。注册与个人资料接口不能更改管理员字段。

## 数据与发布边界

- 迁移 `0022_website` 增加用户平台管理员标记、官网单例、不可变发布记录、独立官网媒体记录。
- 初始内容来自 `app/modules/website/defaults.json`。首次进入管理端后形成数据库草稿；之后以数据库为准，修改默认文件不会覆盖管理员内容。
- 草稿与线上内容分开保存。保存、发布、恢复通过行锁和版本号防止不同窗口静默互相覆盖，冲突时须重新载入草稿。
- 媒体复用现有 CAS 存储，但只能通过平台管理员专用上传接口登记。禁止输入项目文件哈希、任意外链或 HTML。
- 只有当前已发布、且启用板块引用的媒体可匿名读取；未发布/撤下媒体返回404。管理预览使用认证请求，不在链接中暴露 JWT。
- 视频支持 HTTP Range；公开媒体响应不长期缓存，以便撤下后拒绝后续请求。已被访客下载的副本无法撤回。
- 本次没有增加线上云部署、通用用户管理、任意页面编辑器、搜索引擎服务端渲染或第三方统计。真实产品宣传视频可后续直接在管理端替换内置演示。

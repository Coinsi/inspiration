# 平台全局模型

平台管理员登录后，从头像菜单进入「全局模型配置」（`/admin/models`），添加服务并分别选择默认文字、图片和视频模型。服务支持已有的快捷连接、自定义协议、模型目录读取、能力声明、启停、删除和高级路由。

添加服务默认直接填写名称、API 地址和密钥，可先「检测连接」再「保存并读取模型」。检测仅请求模型目录，不保存未提交的密钥或调用生成服务；不提供目录的服务仍可保存后手动添加模型。目录支持搜索、批量勾选和用途调整，批量保存使用事务和稳定的创建标识，失败可以重试。

协议覆盖收在模型编辑的「高级连接设置」内。新模型根据已识别的官方服务地址匹配接入方式，其它地址采用 OpenAI 兼容约定，并明确标为待验证；不会因第三方模型名含 Seedream 就使用火山官方协议。特殊网关仍需配置其真实协议，原有模型协议不会因打开编辑器或改显示名称而改变。官方服务预设仍是可选入口。

普通用户在创作模型列表中直接看到「平台提供」，无需填写供应商密钥。项目已有模型默认配置时优先沿用项目配置；未配置时使用平台默认。个人服务仍只属于本人。旧任务保持提交时的模型快照，不因默认模型变化而改换渠道。

## 权限与数据

- 新增的 `/api/v1/admin/models/model-channels` 和 `/creative-models` 管理接口要求独立的 `is_platform_admin` 身份，项目管理员身份不等价。
- `0056_platform_models` 将渠道、供应商模型和逻辑模型的 `project_id = NULL` 用于平台范围。其它业务实体仍属于项目。平台原始模型使用 `platform_` 前缀，防止与项目原始模型身份混淆。
- 项目管理接口不能绑定、改写、读取全局连接，也不能用连接测试接口借用全局密钥。用户模型目录仅发布模型能力，不提供全局密钥或服务地址。
- 密钥沿用后端加密存储。全局服务调用的供应商费用由平台渠道承担，生成任务和内部配额记账仍在发起用户的项目内。
- 不自动复制个人或项目密钥。平台管理员需明确添加共享服务。
- 全局默认配置写入使用事务锁串行化；任务恢复保留原线路身份及配置校验，不重发状态不明的付费请求。
- 数据库回退时若仍有平台配置则拒绝回退，避免删掉密钥或将共享模型错误归入任意项目。

## 验证边界

后端使用随机 PostgreSQL schema 测试：管理员与项目权限隔离、公开目录脱敏、文字默认与图片理解声明、项目覆盖、预设幂等、默认切换与删除、项目内生成、停用阻断、升级与回退。生成与任务恢复使用本地测试适配器，不代表真实供应商验收。

`frontend/tests/platform-models-browser.mjs` 使用实际 React 组件和拦截的 API 数据，验证全局接口路径、默认模型切换、服务窗口、明暗主题、窄屏、非管理员限制。运行方式参见前端测试说明。

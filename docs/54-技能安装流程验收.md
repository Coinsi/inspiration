# 技能安装流程

日期：2026-09-17。用户指出技能页遗漏影策的安装入口。上一批只重做浏览、阅读和编辑布局，文件导入仍跳入编辑器要求另存；本批补齐独立安装流程，不改设置页，不提交代码。

## 实现

- 参考影策固定提交 `9727656b2b3ccc0db870805396e66c3f655003d4` 的 `web/src/pages/skills/skill-install-modal.tsx`。
- 顶部固定“安装技能”按钮，首组及空库显示安装卡片，筛选状态下仍可从顶部安装。
- 独立窗口提供 Markdown、ZIP 技能包、GitHub 三种方式，支持文件选择和拖入、移除及替换。GitHub 可填写分支/标签和技能目录。
- 读取阶段识别名称、简介、分类、入口与配套文件，不写入技能库。可调整名称、简介和分类，展开检查正文与文件列表。
- 确认安装后直接保存版本1及附件，关闭安装窗口并打开详情，刷新目录和创作技能选择器；无需再进编辑器保存。
- 保留从空白创建技能入口；安装错误保留待安装内容、识别错误可替换文件重试。安装进行中锁定输入和关闭操作。
- 新增 `/skills/install`，按项目、账号与请求编号确定同一次安装。事务内锁定项目，响应丢失后重试返回原技能，不重复建立包和初始版本；同一请求改内容返回冲突，晚到重试不覆盖后续编辑。沿用技能编辑权限和包内容校验，无数据库迁移。
- `.markdown` 与 `.md`、`.txt` 一样按文本读取。ZIP 和 GitHub 继续沿用既有路径、大小、文件数与入口限制。

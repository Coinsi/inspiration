# Inspiration UI 改造验收记录

日期：2026-09-12。范围：前端 UI 实现与本地验证；未提交、未推送。

后续媒体功能已继续补齐，本文保留当时的 UI 阶段记录；当前能力请看 [媒体制作功能与验收](09-媒体制作功能与验收.md)。

## 视觉与页面

- 参考影策仓库的中性背景、细边框、低装饰和内容优先布局，保留 Inspiration 品牌与现有业务文案。
- 深色改为中性黑灰，浅色使用白色与暖灰表面；暖金仅用于主操作、选择及焦点。移除发光、蓝黑渐变和玻璃背景。
- 统一按钮、输入、面板、标签、滚动条、弹窗和抽屉；补充可见键盘焦点与减少动态效果设置。
- AppShell 保留全部路由，桌面可折叠；窄屏为可关闭的导航抽屉，提供跳至内容入口。
- 工作台改为项目概览、制作进度、创作入口、分镜和资产预览。统计来自当前查询范围，移除虚构的 4K、时长、帧率与主配角标签。
- 资产库将创建移入弹窗，搜索、标签、列表、图谱、批量管理和回收站保留；图片与信息分区，操作靠近卡片。图谱可以滚动访问边缘节点。
- 分镜页保留场景、章节筛选、全部规格与文本编辑、AI 拆分、删除和拖动排序；增加键盘排序、保存状态和对应镜头生成/引用/审核入口。
- 分镜预览只展示选定的生成版本；无选定结果、加载、失败各有说明。已有视频结果使用原生播放器，失败显示不可用状态。
- 成片页保留时间线、定剪冻结与基线对比，明确说明尚未接入成片播放。
- 设定、剧本列表、剧本编辑器、资产详情等页面同步使用主题与窄屏布局。AI 助手、版本、权限、审核入口保留。

## 验证结果

- `npm run build`：通过，包含 TypeScript 检查和 Vite 生产构建。
- `git diff --check`：通过。
- `npm run lint`：无法执行；项目原本声明了 lint 命令，但未安装 ESLint，也未提供其配置。本次没有改变依赖或扩展 lint 工程。
- 使用本机 Chrome / Playwright 登录现有示例项目并读取真实 API 数据，没有注入演示数据进行成品截图。
- 工作台、资产库、分镜、拆解工作台、设定、剧本、提示词、镜头看板、成片/基线、成员、设置，共 11 个项目路由通过 390px 页面宽度检查。
- 资产详情、剧本编辑器通过 390px 宽度检查；详情标签支持方向键切换。
- 桌面侧栏折叠/展开、手机菜单导航与自动关闭通过检查。
- 资产搜索与清空、列表键盘排序、图谱入口、批量选择通过检查。
- 新建资产弹窗的初始焦点、Tab 焦点范围、Esc 关闭、关闭后焦点还原通过检查。
- 分镜排序与标题编辑验证了请求格式；删除弹窗默认焦点为取消，Esc 不发送删除请求。测试写入在浏览器拦截，未修改现有业务内容；这不等同于后端写入的端到端验收。
- 分镜直接链接能够打开对应镜头详情，生成、资产引用和审核入口可达。
- 深色、浅色和手机尺寸检查没有发现页面脚本异常。

## 本地预览

当前前端：<http://127.0.0.1:5186>。账号使用项目文档中的 `demo / demo1234`。

前端运行在本任务工作副本；后端为本任务启动的独立进程，监听 `127.0.0.1:8000`，读取现有本地环境与数据库。启动前确认端口空闲，未停止用户已有服务。


# 模型配置体验复核

日期：2026-09-27。用户反馈新版配置仍然不自然，重新核对影策实际前端源码后调整。本轮更新文档 64 中的连接界面设计；原生协议与安全边界不变。

## 对照与问题

参考的是影策的 [默认模型选择](https://github.com/ddcat-ai/open-ai-canvas/blob/main/web/src/pages/settings/model-default-grid.tsx)、[个人渠道设置](https://github.com/ddcat-ai/open-ai-canvas/blob/main/web/src/pages/settings/channel-settings-pane.tsx) 和后台渠道管理代码。演示站本轮访问超时，因此以下结论来自源码，不冒充实时视觉对照。

原界面默认暴露逻辑模型、渠道模型、路由、权重和积分，再增加一个独立连接向导。用户在开始创作前需要理解过多管理概念。影策把日常默认选择和技术渠道管理分开；自定义渠道的连接信息及模型能力也集中管理。

## 本轮实现

- 设置入口改为「模型服务」，默认显示「模型选择」；按图片、视频、文字分组，显示模型、来源、配置状态与当前默认。
- 已有服务模型可以直接设为默认。后台自动复用或创建目录关联，重复选择不重复创建；保留原线路、权重和积分。不同媒体类型的默认互不覆盖。
- 「服务连接」改为平铺卡片，就地展开模型列表，提供编辑连接、读取模型与添加模型。
- 内置火山方舟、MiniMax 与自定义服务集中到同一个添加入口，取消两步向导；内置服务仍支持填 Key 后批量启用模型，自定义服务保存后在卡片内管理模型。
- 路由和积分等原有能力移入「高级管理」。同一服务按钮重复点击不会清空输入。默认选择支持键盘方向键、Home/End。
- 配置仍然对当前项目生效，未将项目密钥自动迁移成个人或全站连接；旧作品与任务快照不变。

## 验证

- 后端默认选择、逻辑模型、快捷连接与渠道相关测试 **29 项通过**。覆盖重复选择、默认互斥、原多线路及积分保留、文字创作使用默认、不可用模型拒绝、项目隔离与只读权限。
- 前端生产构建通过；既有 Director 大包提示仍在。
- 浏览器独立验收项目：直接选未绑定的 mock 模型成功，刷新后保持选中；键盘切回原默认成功。就地展开模型、内置服务切换、自定义入口及 Escape 关闭通过。
- 390px 宽度下文档无横向溢出；正常桌面视口完成视觉检查，页面无控制台错误。
- UI 验收仅新增本地 mock 配置；没有提交付费生成，没有修改用户示例项目中的密钥或默认模型。

## 后续边界

个人渠道与系统共享渠道的作用域、更多原生模型预设、真实账户权限/余额/生成验证仍需独立实现。保存连接或显示「已配置」不代表真实上游已验证可用。本轮没有提交或推送代码。

# 06 · UI 重构方案

| 项目 | Inspiration —— 影视/动漫 AIGC 资产管理与生产平台 |
|---|---|
| 文档版本 | v1.0（已实现 U1–U4） |
| 目标 | 简洁 + 好看:从"能用的后台"升级为"像高端流媒体/创作工具"的界面 |
| 落地 | Teal 强调 · 深浅双主题可切 · 侧边栏骨架 · 海报墙 · 资产 hero · 镜头 Kanban + 抽屉 · 登录页 · Toast/骨架屏 |

---

## 1. 设计参考(实地调研)

| 参考 | 借鉴点 | 链接 |
|---|---|---|
| **Jellyfish**(Jellyfin 主题) | 深色海报墙、圆角卡片、强调色在暗底跳脱、角标徽章、backdrop 沉浸感、悬停浮起 | [github.com/n00bcodr/Jellyfish](https://github.com/n00bcodr/Jellyfish) |
| **Linear / Vercel 仪表盘** | 侧边栏(240–280px)+ 内容区、KPI 指标条、12 栅格、类型驱动、零装饰动效、严格色彩系统 | [vercel.com/try/new-dashboard](https://vercel.com/try/new-dashboard) |
| **shadcn/ui** | 组件源码内置仓库、可定制、设计系统基座(已采用) | [ui.shadcn.com/examples/dashboard](https://ui.shadcn.com/examples/dashboard) |

**核心理念:用 Linear 式的"克制应用骨架"承载 Jellyfin 式的"海报墙内容"。**
左侧安静的导航 + 主区富媒体(角色头像墙、镜头缩略图、生成变体墙),深色为主、强调色点睛。

## 2. 设计令牌(Design Tokens)

### 2.1 颜色(深色主题 · 主)
| 角色 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0C0E12` | 全局底色(近黑微蓝) |
| `--surface` | `#14171D` | 面板/侧边栏 |
| `--card` | `#1A1E25` | 卡片 |
| `--border` | `#262B33` | 描边(暗底靠描边而非重阴影分层) |
| `--fg` | `#E7E9EC` | 主文字 |
| `--muted` | `#9AA1AB` | 次要文字 |
| `--primary` | `#7C6BF0` | 强调(优雅violet,暗底跳脱) |
| `--primary-fg` | `#FFFFFF` | 强调上文字 |
| 语义色 | success `#34D399` · warning `#FBBF24` · danger `#F87171` · info `#60A5FA` | 状态/徽章 |

> 借鉴 Jellyfish 的"多配色"思路:强调色做成可切换(violet/teal/coral…),其余令牌不变。

### 2.2 浅色主题(次)
`--bg #F7F8FA` · `--surface #FFFFFF` · `--card #FFFFFF` · `--border #E7E9EC` · `--fg #16191D` · `--muted #6B7280` · 强调同 violet。`<html>` 加 `.dark` 切换。

### 2.3 其它
- **圆角**:卡片 12px、输入/按钮 8px、徽章 full、头像 full
- **间距**:基准 4px;区块间 20–24px;卡片内 16px
- **阴影**:暗底极弱(`0 1px 0 rgba(255,255,255,.03)` + 描边);悬停轻微 `translateY(-2px)` + 强调描边
- **字体**:UI 用 Inter + `PingFang SC`/`Microsoft YaHei` 回退;**编号(SC012-SH003)用等宽字体**做"工业感"徽章
- **动效**:仅状态/悬停的 120–160ms 过渡,无装饰性动画(Linear 原则)

## 4. 富媒体组件模式(Jellyfish 风)

- **资产海报卡**:封面图(16:9 或 2:3)圆角 12px → 悬停浮起 + 强调描边;左上**类型徽章**、右上**状态点**;下方名称 + 等宽编号。网格 `auto-fill minmax(180px,1fr)`。
- **角色卡**:竖版海报 + 圆形头像;无图显优雅占位(首字母 + 柔和渐变)。
- **镜头看板**:**Kanban**——按制作状态分列(待设计/概念图/生成中/待审/返修/定版/已入剪),卡片带缩略图 + 编号 + 负责人头像;点开右侧**抽屉(slide-over)**看详情/生成/评审,而非整页跳转。
- **生成变体墙**:网格/瀑布流变体,悬停浮现操作;**钦定**项加强调描边 + 角标。
- **进度 KPI 条**:顶部 4–6 个指标卡(全片镜头/定版/生成中/待审 + 配额已用),Linear 式指标条。
- **资产详情 hero**:代表图做**模糊 backdrop 横幅**(Jellyfin 沉浸感)+ 前景圆形头像 + 标签页(信息/参考图/概念图/版本)。
- **空态 / 骨架屏 / Toast**:替换当前 `alert()`,统一轻提示;加载用骨架屏。

## 6. 实施方式(技术)

- **令牌**:`index.css` 定义两套 CSS 变量(HSL),Tailwind `theme.extend.colors` 全部指向变量;`.dark` 切换。
- **组件**:新增 shadcn 风格基础件(手写内置):`Badge / Avatar / Tabs / Dropdown / Tooltip / Skeleton / Toast / Sheet(抽屉)`。
- **图标**:`lucide-react`(已依赖)。
- **骨架**:新增 `AppShell`(Sidebar + Topbar),替换现有 `ProjectNav`;各页改为放进 AppShell 的内容槽。
- **不改后端**:纯前端重构,接口不动。

## 7. 分阶段(建议)

| 阶段 | 内容 | 收益 |
|---|---|---|
| **U1** | 设计令牌 + 深色主题 + **AppShell 侧边栏** | 一次性最大观感提升(骨架级) |
| **U2** | 资产海报墙 + 角色卡 + 资产详情 hero | 富媒体质感 |
| **U3** | 镜头 Kanban + 生成变体墙 + KPI 条 | 生产体验 |
| **U4** | 登录页 + 空态/骨架/Toast + 明暗切换 + 微过渡 | 精致收尾 |

> 建议先做 **U1**:它把"顶部标签 + 朴素卡片"换成"侧边栏 + 深色精致骨架",视觉立刻到位,且不影响功能。

# 手机浏览器适配

本次是存量工作台的设备适配：沿用现有颜色、字体、卡片与业务流程，增加手机布局和触控入口。改动位于 `codex/desktop-clients` 独立工作目录，不改主目录，不部署线上，不制作 Android/iOS 安装包。

## 设计约束

- 用户主要任务：打开项目、记录创作意图、浏览与上传素材、查看任务、调整画布/导演台/剪辑中的对象。
- 北极星：手机一次专注当前内容，必要工具随手可达；不通过缩小整个桌面工作台塞进屏幕。
- 沿用当前应用的深浅主题、图标、共享控件与命名，不重新探索品牌方向。
- 常规列表按宽度换行；多面板编辑器将工具分区，不移除业务能力。
- 标准控件与关键触屏操作至少 44px；手机文字输入使用 16px，避免 iOS 聚焦时自动放大。
- 以 360/390px 竖屏为手机基线，复核桌面 1440px；时间线、画布、分类条可以在自己所属区域平移或滚动，页面本身不横向撑开。

## 实现

- 导航：抽屉保留所有工作区入口；当前页面名称在项目名下方显示；打开抽屉时后台内容不可交互，关闭后恢复焦点。
- 高度与弹窗：跟随 Visual Viewport 调整固定区域，支持刘海与底部安全区；弹窗正文滚动，打开时锁住背景滚动。保留用户缩放。
- 创作对话：输入区随可用高度收缩，工具可换行，发送、模型、添加内容等入口保留；项目首页的项目选择单独成行。
- 素材：手机列表采用紧凑条目，筛选层不越界；触屏直接显示预览提示，不依赖鼠标悬停。
- 技能与提示词：搜索、安装、新建分行；阅读器目录与正文共享可用区域，工具条不会被目录覆盖。
- 任务与设置：详情关闭按钮、筛选与分类支持触控；长名称和错误信息换行，设置分类在区域内滚动。
- 画布：触屏默认抓手，可切换区域选择；属性使用底部面板，菜单限制在可用高度内，仍支持新增节点和编辑。
- 导演台：手机切换“画面与输出 / 场景与布景 / 对象与机位”；面板保持挂载，切换不清除状态。
- 剪辑：默认聚焦预览，属性按需展开在预览附近；片段、音轨、字幕与裁切操作保留，拖柄扩大。
- 写作与分镜：制作工具菜单以整行工具栏定位，长场景名可收缩；手机镜头导航允许换行，场景选择与关闭入口保持可触达。

动效沿用现有 150–160ms 过渡，抽屉增加短距离进入，剪辑打开属性平滑定位；尊重 reduced-motion。没有增加装饰文案或新的品牌样式。已有说明保留用于识别任务和手势，不删除必要标签。

## 验证方式与边界

使用仓库现有 Playwright 脚本模式，在独立 Vite 服务中拦截所有 API，检查带数据的页面、弹窗、编辑器面板和失败状态；不会创建线上项目、调用模型或写入用户数据。fixture 图片为测试图，不能代表真实作品。

测试脚本：`frontend/tests/mobile-responsive.mjs`，运行变量见 `frontend/tests/README.md`。测试环境允许模拟短视口验证控件布局，但不能替代 iPhone/Android 真机软键盘、Safari 媒体解码、复杂多指手势和持续性能测试，也不证明真实服务端保存成功。

### 2026-10-23 验证记录

- 页面矩阵：13 个带测试数据的页面 × 390px 深色、360px 浅色、1440px 桌面深色，共 39 项通过；无页面 JavaScript 异常或文档横向溢出。证据：`test-results/mobile-final/report.json` 及同目录截图。区域内有意横向滚动的时间线、建议条等不作为页面溢出。
- 交互回归：主代理实际运行两种手机尺寸，每种重复 3 次，每次 8 项，共 48 项通过。覆盖抽屉关闭与焦点恢复、对话草稿刷新与 520px 短视口、项目弹窗、素材列表/筛选、技能阅读器/目录、画布属性、导演台三个面板及剪辑属性。后面三个编辑器还检查了失败保存不清空输入。证据：`test-results/mobile-interactions-repeat/report.json`。
- 补充场景：360px 浅色及 390px 深色下，写作工具菜单、长剧本/场景名和场景选择器均可操作，无页面异常或写请求。证据：`test-results/mobile-extra/report.json`。其余小说、设定、剧本目录、故事板、作品及成员页检查了已有响应式实现，没有将静态审查计入上述交互数量。
- 独立视觉评审：另一代理查看了 18 张手机/桌面真实截图，另复核写作与分镜 6 张补充截图，没有发现阻断操作的遮挡或裁切。评审发现的原始 `asset.scene` 标签来自测试数据枚举错误，已改为服务端使用的 `location`；不是产品翻译修复。旧交互截图保留当时数据，修正后素材证据单独保存于 `test-results/mobile-extra/*-assets-corrected.png` 及 `assets-corrected-report.json`。
- `node node_modules/typescript/bin/tsc -b --pretty false` 与 `git diff --check` 均通过。`npm run lint` 无法执行：仓库声明了脚本但未安装 ESLint；没有为本次样式适配修改项目依赖。未运行生产打包。

截图使用测试图片和项目名；所有 API 均由本地 fixture 拦截，保存失败为预期的 HTTP 403。没有登录真实账号、运行模型、改变后端数据或发布线上。

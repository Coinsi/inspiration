# 素材目录与批量整理

## 批次18范围

视频库提供项目内层级目录、新建、重命名、调整父目录、删除空目录；支持全部目录、未归档、当前目录直接视频三种范围。目录路径保存在网页地址，刷新后保留当前目录。

目录限制为每项目1000个、最多8层。同级名称忽略首尾空白和大小写判重；禁止目录进入自身或后代，也校验移动整棵子树后的深度。更名与移动携带目录修订号，旧编辑不能覆盖别人刚保存的目录。

勾选视频或选择本页后，可将最多100项素材原子移动到目标目录。检查所有素材的项目归属与所选时的原目录，遇到越权、缺失或并发变更时整批拒绝，不出现部分移动；同一结果的重试可安全返回。只改素材目录，不改变版本编号、文件哈希、镜头时间范围、生成输入或复用来源。

在某目录中新上传或跨项目复用的视频直接放入该目录。对已有素材上传新版本仍沿用其已有归档位置。回收站素材也可以移动；删除目录会检查子目录与全部素材，包括回收站，不连带删除视频。

项目锁统一保护目录变更、归档移动和向目录加入素材；批量移动再按固定顺序锁素材，避免与引用/删除产生不一致。所有目录和批量整理操作写入审计。

# 影策功能对照与补齐计划

日期：2026-09-12。基线：Inspiration main `bbedfcd`。目标是补齐创作能力，保留现有小说、剧本、资产版本和镜头溯源体系。以下拆分为可独立交付的阶段；“有入口 / 代码”与“真实服务验收通过”分别记录。

## 交付顺序

1. **A 创作编辑基础（已完成首版）**：局部重绘、提示词优化首版、片段拆分 / 复制 / 撤销重做。独立分支 `codex/yingce-feature-parity`，复用现有权限、素材存储和任务队列。
2. **B 视频与角色生产**：真实视频适配与验收、抽帧 / 音轨、角色视角与表情预设。视频依赖供应商端点、凭据、协议和计费规则；不将兼容网关壳算作官方服务已接通。
3. **C 声音与成片**：配音、字幕、多轨音频及混音、转场、自然语言剪辑。先完成音频资产与时间线模型迁移，再扩展 UI 和渲染器。
4. **D 自由画布**：实体引用、节点编辑与持久化、连线生成、批次与布局；与现有分镜双向关联。
5. **E 3D 导演台**：分镜关联的场景、相机与灯光、预演输出。独立里程碑，不用静态示意图冒充可用的 3D 编辑器。
6. **F 工作流扩展**：Agent / 技能、外部素材库、分享与个性化。

## 每阶段完成标准

- 页面可进入、输入可验证、结果实际落库或导出；刷新后状态符合设计。
- 云端能力分成协议测试、真实请求、产物质量三个检查项。Mock 只能证明本地流程。
- 检查项目隔离、角色权限、损坏输入、服务失败、重复提交与可恢复性。
- 使用隔离测试 schema 和临时素材；现有用户项目只做必要只读检查。
- 更新本文件状态和验收证据；未完成项保持未完成。未配置外部服务时继续无依赖的开发任务。

# 账户与项目菜单分离

日期：2026-09-18，批次42。按用户确认的方向，将个人账户、项目管理与创作功能分开。代码未提交。

## 调整

- 项目首页和项目工作区共用右上角头像菜单，展示当前登录用户，提供账户信息、外观与语言、退出登录。
- 账户信息使用现有登录接口中的用户名和显示名称，仅展示实际已有信息；本批未增加资料修改或密码修改接口。
- 主题、语言放入账户偏好窗口，自动保存到当前浏览器并跨项目共用，不写入项目配置。
- 顶部项目名称成为菜单，提供项目资料与封面、创作默认项、渠道与模型、成员与权限、更多项目设置及切换项目。
- 左侧移除账户区、设置、成员和任务入口。“工作台管理”调整为“创作工具”，保留技能库和提示词库。工作台内容区重复的项目设置按钮移除。
- 右上角提供任务中心入口，使用已有的项目任务页查看进度。没有添加无数据来源的通知按钮或虚构未读数量。
- 项目设置页保留项目级资料、创作偏好、渠道模型、配额及外部AI连接；外观与语言迁出。旧的 `settings?section=appearance` 地址会自动打开账户偏好窗口。
- 菜单支持点击外部关闭、Escape关闭与焦点归还、方向键及Home/End选择。桌面、收窄创作工作区与手机使用相同入口。

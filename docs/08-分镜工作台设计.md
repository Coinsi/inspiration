# 08 · 分镜工作台(Storyboard)设计与实现

| 模块 | 分镜工作台 —— 场景级镜头分镜设计 |
|---|---|
| 位置 | 拆解工作台(小说→场次+粗镜头)→ **分镜工作台(按场景精修镜头序列)** → 生产(镜头看板)→ 成片 |
| 关系 | 与「镜头看板」操作**同一批 Shot 实体**:看板是全项目按制作状态的生产看板;分镜是按场景把该场镜头当**有序分镜序列**来设计 |
| 状态 | ✅ 已实现并 live 验收 |

## 数据模型
复用 `Shot`,新增**一个 JSONB 列 `storyboard`**(可扩展,免每加一个字段就改库):
- 景别 `shot_size`、机位 `camera_angle`、运镜 `camera_move`、转场 `transition`、画面比例 `aspect_ratio`、节奏 `pacing`(下拉,存稳定 key)
- 时长 `duration_sec`(数字)、对白 `dialogue`、音乐音效 `audio`、备注 `notes`(文本)
- 迁移 `0002_shot_storyboard`(已对本地库 ALTER + stamp)

## 后端接口
- `GET /scenes`:全项目场景 + 镜头数 + 章节/小说上下文(支持 `?novel_id=&chapter_id=` 筛选)
- `POST /scenes/{id}/shots`:场景末尾新建镜头
- `POST /scenes/{id}/shots/reorder`:`{shot_ids:[…]}` 重排
- `DELETE /shots/{id}`:软删镜头
- `PATCH /shots/{id}`:扩展支持 `storyboard`(按 key 合并,空值清除)
- `compose-prompt`:**分镜规格自动拼入提示词**(景别/机位/运镜 → 英文术语,如 `close-up, camera push-in`;画面比例 → `16:9 aspect ratio`)
- `POST /scenes/{id}/breakdown`:**AI 拆分镜** —— 用已配置的云 LLM,把一个场景(回溯来源章节正文)拆成多个带分镜规格的镜头,追加到该场景。LLM 从受限取值里选 `shot_size`/`camera_move`,返回 title/description/duration/dialogue;落库即带 storyboard。
  - 适配器:`DecompositionStrategy.suggest_storyboard_shots()`(默认实现回落 title/description;`cloud_llm` 覆盖出完整规格)

## 前端
- 侧栏「生产」组新增「分镜」入口
- 全高两栏:**左** 场景列表(按小说/章节筛选,显示每场镜头数)/ **右** 选中场景的镜头分镜序列
- 每个镜头一张卡:拖拽手柄 + 序号 + 缩略图占位 + 标题 + 时长 + 6 个规格下拉 + 画面描述/对白/音乐音效/备注;**原生拖拽排序**、新建/删除(带确认)
- 全程中英双语;规格下拉存 key、按语言显示标签

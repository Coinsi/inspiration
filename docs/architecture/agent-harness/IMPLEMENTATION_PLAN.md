## 实施约束

- 复用现有 GenerationJob、计费、素材库和工程领域服务；新建 harness 自有编排记录。
- 保留工作区原有 prompt/skill/封面功能改动；不回退、不提交其他任务未完成内容。
- 保留旧 Agent 和历史任务读取路径；先以显式执行种类区分新旧运行，再接统一入口。
- 数据库变更通过 Alembic；测试使用独立 schema、临时媒体，不清空用户数据。
- 模拟模型只验收编排协议；模型质量、外部工具兼容和真实媒体能力单独记录，不能互相代替。
- 涉及真实供应商费用的验证先使用已有可执行的低成本路径；未验证能力明确列出，不编造结果或自动采用。

## 明确的验收边界

- 模拟决策不证明云模型的规划、视觉判断或创作质量；真实供应商协议及费用仍使用其原有契约，未知外部提交不重发。
- 反馈定位固定原预览文档与修订，歧义显式返回；不会把旧时间码静默套到新版影片。
- 选择性操作目前支持原生输出中的 source/mask 引用；任意历史参数、时间线重排和跨层同步不能冒充通用自动撤销。
- 模型 tokens 无供应商实际用量时保留估算预留；不会记成零消耗。存储和传输采用预留上限，产物落库后按实际字节结算，不虚构云账单金额。

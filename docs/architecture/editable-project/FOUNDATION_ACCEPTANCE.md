# 可扩展作品工程底座验收

2026-10-18。本轮验收对象是可继续扩展的工程底座，不是全部创作工具或无人值守影片生产。

## 已落地的完整链路

作品拥有自己的工程身份；图像、音频、合成及剪辑文档使用固定修订和资源依赖。操作先产生候选，多文档变更整体校验、预览、审核采用。历史不会跟随最新文件或最新模型变化。工作剪辑与作品相连，可以从作品进入剪辑，再返回查看候选和采用结果。

同一素材的多次使用由实例区分；修改选中实例或嵌套路径创建新修订，不覆盖其他使用。依赖分析报告受影响的输出和时间范围。并发修改采用整作品版本比较，冲突明确失败，不静默覆盖。

本地预览有持久投递、租约及结果发布校验；工程导出/导入有持久任务、进度、取消、重试、上传续传、容量预留和过期清理。完整归档携带验证过的媒体，已经验证源数据库和源存储移除后仍可恢复并渲染。候选恢复不会自动替换采用版本。

## 后续功能如何接入

| 后续需求 | 复用的工程能力 | 还需要开发的具体能力 |
| --- | --- | --- |
| 修改眼神、武器、局部画面 | 固定素材、蒙版、使用实例、候选及采用 | 对应生成/修复工具与交互；不保证模型修改质量 |
| 调整局部声音、换配音 | 音频文档、增益/混音、时间映射、同步复核 | 配音供应商、对口型、精细音频编辑界面 |
| 平台内特效、动画 | 类型版本、嵌套合成、依赖及预览执行器注册 | 各特效算子、关键帧/曲线、视频图层、色彩与 GPU 执行 |
| 重新编排打斗或剧情 | 原子多文档变更、影响分析、候选和历史 | 叙事/分镜领域适配器及质量评估；工程结构本身不判断精彩程度 |
| 多 Agent 同时参与 | 独立工具、固定输入、版本冲突检查、不可变结果 | 调度、任务拆分、上下文选择、费用管理和冲突协调策略 |
| 新业务类型 | 类型、迁移、实例、执行器适配契约 | 新类型实现与验证；不能仅存任意 JSON 就宣称可编辑可执行 |

## 明确边界

- 当前并发采用以整作品为单位；没有自动分支合并。
- 音频/合成 v2 的时间映射已有执行验证；旧剪辑轨道及嵌套路径的跨文档同步锚点尚未实现。
- 基础图像、音频和静态层合成可执行；高级特效不在已支持名单内，不能通过基础预览推断其完成。
- 未知扩展可保留迁移，无法执行时明确拒绝，不能悄悄忽略后导出。
- 归档采用一个持久暂存卷；未完成跨主机调度、浏览器下载自动续传或超大归档吞吐压测。
- 暂存配额不等于 SaaS 全部存储账单治理；物理素材 GC 默认关闭。
- 当前用户库存在此前抽查发现的历史缺失媒体记录；本轮没有伪造内容补齐，也不能保证原先丢失的素材可恢复。

代码、设计及执行证据分别见 CURRENT_STATUS.md、CONTRACTS.md、DELIVERY.md。将来增加能力仍可能需要格式迁移，但已有作品有固定版本、显式迁移和未知扩展保留机制，不要求推翻现有工程。

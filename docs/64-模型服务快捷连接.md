# 模型服务快捷连接

2026-09-27。用户确认减少配置步骤，首批将原生适配与快捷设置放在一起交付。此文覆盖本轮范围，不代表影策全部协议已迁移。

## 创作者与管理员

项目设置 → 渠道与模型 → **连接模型服务** → 选择供应商 → 填密钥并选择模型 → 保存。

- 地址、模型编号、协议、参数和参考图能力由服务端预设，用户无需依次建渠道、配置实际模型、再绑定创作模型。
- 新项目自动采用第一个对应类型模型；已有默认模型不被替换。
- 高级设置可修改服务名称与同协议代理地址。其他服务保留手动接入与自定义模型入口。
- 密钥只保存在已有服务端凭据体系，不回传、不放进浏览器持久存储或任务快照。生产环境仍须配置正式加密密钥。
- 保存不调用供应商，也不产生生成费用。“已配置”不代表已验证账户权限、余额或生成成功。
- 项目锁与单次数据库事务保证三层配置全部保存或全部回滚。相同地址和密钥复用已有启用渠道；相同渠道模型不重复创建。第二份密钥可为同一内置模型追加线路；手动创建的同名模型不会按名称猜测合并。
- 原有配置及默认项保留，已停用模型不会被向导悄悄重新启用。

## 首批适配范围

| 服务 | 内置模型 | 协议与输入 | 本轮边界 |
| --- | --- | --- | --- |
| 火山方舟 | Seedream 4.5 | JSON `/images/generations`，文本、单图和多图参考 | 单张输出；预设 2K/4K 和常用像素尺寸，无蒙版、组图或流式响应 |
| 火山方舟 | Seedance 1.5 Pro | `/contents/generations/tasks` 创建及查询，文本、首帧、首尾帧 | 预设 480p/720p、常用 4–12 秒选项和画幅；未接视频/音频参考、音轨开关、草稿任务 |
| MiniMax | Hailuo 2.3 | `/video_generation`、`/query/video_generation`、`/files/retrieve` | 文本或起始参考图，768P/1080P、6/10 秒；1080P 与 10 秒的无效组合在提交前拦截 |

火山方舟使用 API Key；不是即梦网站 Cookie，也不是要求 AK/SK 签名的另一套火山视觉接口。MiniMax 使用开放平台 API Key。每次一个结果；未知内部积分不等于免费。

服务端目录接口 `GET .../model-channels/presets`；一次保存接口 `POST .../model-channels/connect`。两者均受项目 `provider.manage` 权限约束，没有向普通创作者开放凭据。

## 任务与异常

原生接口使用有限响应体、明确超时和禁止鉴权请求跟随重定向。参数组合、参考图角色与数量在提交前验证。原始上游返回体、密钥及参考图数据不出现在错误提示中。

只有明确提交拒绝（401/403/404/429）可以自动切换。超时、5xx、缺少任务编号、未知应用错误都不能证明未生成，因此不自动重发。

火山与海螺视频保存上游编号后，轮询或下载失败可恢复原任务；端点改动会阻止查询到新地址。恢复过程中再次失败仍保持原编号。同步图片结果还没有持久暂存，因此保存失败后不能无成本自动恢复。

## 剩余项

- Gemini/Nano Banana、Veo、xAI、更多 Seedance/MiniMax 版本、其他参考仓库协议按各自官方合同独立接入；不能仅添加模型名字就标记为完成。
- 有真实账户后验证每个模型的权限、余额、输出、计费及素材入库；本轮未做真实付费调用。
- 同步图片结果的持久化暂存、多结果生成、复杂参数能力矩阵和计价维度继续独立处理。

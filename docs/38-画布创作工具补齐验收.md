# 画布创作工具补齐（批次24）

日期：2026-09-16。完成用户确认的七项画布补齐范围，保持 UI 与创作工具优先；代码未提交。

## 已落地的使用流程

| 能力 | 操作与保存行为 |
| --- | --- |
| 文件直接落入画布 | 图片或 MP4 可直接拖到画布，截图可直接粘贴；多文件逐个显示状态，按落点放置。失败文件可重试，响应丢失后重试同一请求不会重复创建素材。输入框内的普通粘贴保持原行为。 |
| 智能引用 | 生成节点的提示词输入 `@`，选择已有画布节点，插入带来源身份的引用并自动建立对应连线。已有素材固定到实际版本；模型输入中的参考图编号与真实图片顺序对应。删除或改接连线时清理失效绑定，撤销可恢复。 |
| 自由绘图 | “画布工具→自由绘图”：画笔、直线、箭头、矩形、椭圆、颜色、粗细、笔画撤销/重做。保存为独立 PNG 素材节点，可继续接入生成参考。 |
| 连线与整理 | 拖动连线端点改接；节点/空白处右键打开工具；同一项目跨画布复制粘贴，节点和连线编号重新分配，素材固定版本保持。支持 Ctrl/⌘ A/C/V，以及已有 D/Z/S；八种对齐/等距分布和可选 24 像素网格吸附。 |
| 图片编辑 | 选中图片→“绘图与裁切”，在原图尺寸上标注与裁切，另存同一对象的新版本，保存来源图片身份，原图不覆盖。来源原图可回看。 |
| 执行结果复用 | 默认关闭。“复用未变化的结果”开启后，对比提示词、参数、对象/素材版本、输入关系及实际上游结果。定点生成会重新生成所点节点；整图运行可跳过不变结果。上游重新生成新版本，即使提示词相同，下游旧结果也不能命中。界面显示“已复用”。 |
| 视频与交付 | “画布工具→从视频素材库选取”：选择原片版本、时间范围与所属镜头，提取参考帧、视频或音轨，处理任务持久保存，结果放入画布并保留来源版本/范围。可导出带原始媒体、画布文档和离线 HTML 的 ZIP；也可复制仅项目成员能打开的只读链接。 |

文件导入、编辑产物、执行和视频提取沿用项目权限、素材版本、后台任务及引用保护。没有增加数据库迁移，没有修改主预览或用户创作项目。

## 数据与界面边界

- 直接导入支持 PNG/JPEG/WebP/MP4，单文件最多 100 MB、每次最多 20 个；大视频走已有分块素材库。
- 绘图空白画面为 1600×900；原图编辑最长边 8192、最多 4000 万像素。保存的是 PNG，笔画不是可跨刷新编辑的矢量图层；不宣称提供完整图像编辑器。
- `@` 从当前画布已有节点选择；项目中的新素材先放入画布。每节点最多 50 个引用，原有模型是否支持图片参考仍依其真实能力声明。
- 跨画布复制限同项目，跨项目继续走素材库复用。粘贴先由服务端校验，不能绕过对象所属项目校验。
- 复用查找最近 20 个批次；仅使用成功且仍有效的结果。不确定时重新执行，关闭开关即按原流程运行。
- 视频/音轨单次提取最多 60 秒；需要选择已存在镜头归属。素材的删除依赖仍保留原片与派生结果关系。
- 离线包上限 512 MB，包含实际文件，不携带登录凭据或临时鉴权媒体链接。在线只读链接仍要求项目权限；**公开匿名链接、过期/撤销分享未做**，外部分享当前使用离线包。
- 只读浏览隐藏保存/执行/撤销操作，缩放平移不会写回或覆盖编辑草稿。只读链接是界面浏览模式，不改变成员原有权限。

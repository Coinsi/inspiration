# 工作台就地模型选择与创作

日期：2026-09-27。按用户要求将日常选型移入工作台输入区，参照影策的 [创作输入区](https://github.com/ddcat-ai/open-ai-canvas/blob/main/web/src/pages/create/creation-workspace.tsx) 和 [模型选择器](https://github.com/ddcat-ai/open-ai-canvas/blob/main/web/src/components/model-picker.tsx)。本轮参考源码，未完成演示站实时视觉对照。

## 本轮实现

- 项目工作台输入区切换图片、视频、文字，按类型搜索和选择模型；离线测试独立展示，不自动代替真实模型。
- 图片和视频按模型能力展示参数，记住各模型的选择；切换模式、模型和打开服务设置时保留提示词及参考。
- 当前项目管理员可就地连接或管理模型服务，无需跳转设置页面；普通成员查看模型，服务配置仍遵守原权限。
- 本次选择随请求发送，不修改项目默认。图片、视频保存任务输入快照；文字将明确选择的模型交给已有创作助理，不静默回退到项目默认。
- 图片、视频以独立工作台作品保存，复用任务队列、配额、重试及下载，不自动创建剧本镜头。工作台展示最近结果，支持再次创作和图片参考复用，任务中心可返回来源。
- 参考选择来自当前项目已有 Generation 图片记录（已生成或通过相关入口上传的图片），保存来源 ID。视频首尾帧由模型能力约束，切回图片时按普通参考使用。不兼容时提示调整，不自动丢弃参考。
- 媒体提交使用请求键处理重复点击和响应丢失重试；相同键但不同内容返回冲突。项目隔离、只读权限、额度不足时无孤立作品记录均有覆盖。
- 服务弹窗复用统一焦点管理，支持嵌套编辑；文字结果区区分处理中、待审阅、暂停、取消及完成。

# 统一创作模型与多渠道路由

日期：2026-09-27。参考影策公开实现中的逻辑模型、渠道模型和提交路由设计，结合本项目已有 Python 任务、素材与权限体系实现。本轮不复制演示站私有供应商配置，不视作真实模型生成验收。

## 使用方式

项目设置 → 模型与渠道包含两个入口：

1. **连接模型服务**：选内置供应商、填写密钥、勾选模型，一次保存自动建立渠道与创作目录，详见 [64-模型服务快捷连接](64-模型服务快捷连接.md)。其他供应商可在“供应商渠道”手动配置。
2. **创作模型**：设置创作者看到的名称，例如某个图片或视频模型；为它绑定一个或多个渠道模型。优先级数值越大越优先，同优先级按权重随机选择。

同一个创作模型可以绑定多个供应商，不要求它们的上游模型编号相同。管理员需要确认绑定的线路确实提供期望的模型，不会仅凭名称自动合并。

“整理已有模型”将未绑定的渠道模型分别建立为创作模型，可重复执行。已有渠道、密钥、画布选择与历史任务保留。被绑定的渠道模型从新创作的选择列表隐藏，但历史选中的直连配置仍可使用。新目录不自动把历史配置换成别的模型。

图片和视频模型提供“检查线路”：按完整参数组合列出候选与不匹配原因，只检查本地配置，不访问上游。参数下拉框展示各线路的能力并集；提交时必须至少有一条线路支持整组参数，不能拼接不同渠道能力假装可用。

## 任务与失败处理

- 提交时冻结模型版本、候选顺序、渠道地址摘要、渠道模型配置和积分估算，不保存密钥到任务快照。
- 任务中心显示创作模型名和实际渠道调用记录。生成结果保留实际模型编号及路由来源。
- 每次外部提交前先持久化“正在提交”，避免进程中断后盲目重发。
- 仅适配器确认提交被拒绝时允许切换，如支持的协议返回 401、403、404、429。超时、500、缺少任务编号等状态不能证明没有生成任务，因此停止切换并禁止自动重试。
- 上游已接受的任务不会因轮询、下载或入库失败而切换渠道。
- OpenAI Videos、火山方舟视频及 MiniMax 海螺协议保存了上游任务编号后，可以恢复查询和下载原结果，不重复提交。恢复过程中配置错误再次失败，下一次重试仍保留原任务编号。
- 同步图片结果的恢复下载目前没有通用支持，不能把“重试”当作无成本操作；已接受后的失败会禁止自动重发。
- 手动重试上游明确失败的任务属于新的生成尝试，可能产生新的上游费用。

## 积分与权限

图片支持按结果数量，视频支持按结果数量或秒数计价。创作模型可以统一设置积分，也可以继承实际渠道模型积分。按可用线路的最高积分预留，成功后按实际选中的线路结算。

积分是项目内部配额，不是供应商账单。未配置积分会明确提示，未知成本不计入内部额度，不代表上游免费；生产使用前应配置所有启用线路的计价。

模型与渠道仍按项目隔离，由具有 `provider.manage` 权限的成员管理。普通成员通过创作入口使用模型，不能读取渠道凭据或编辑路由。密钥仍使用项目既有凭据存储机制；生产部署必须配置 `CREDENTIALS_FERNET_KEY` 并妥善迁移旧凭据，不能把开发环境兼容编码视为加密。

## 数据与接口

- 迁移 `0024_creative_models`：新增 `creative_model`，为 `generation_job` 增加 `routing_state`。不覆盖已有渠道或历史任务。
- `/api/v1/projects/{project_id}/creative-models`：管理目录、创建模型。
- `PUT .../creative-models/{id}`：按版本保存，冲突返回 409。
- `POST .../creative-models/import-profiles`：显式整理旧渠道模型。
- `POST .../creative-models/{id}/simulate`：图片/视频路由配置检查。
- 既有 `/providers`、能力检查、预估与生成接口兼容 `creative_...` 模型标识，画布和镜头不必维护另一套任务接口。

### 浏览器补验

在独立开发验收项目“模型体系 UI 验收 0927”中，使用两个本地 mock 渠道完成：

- 浏览器创建统一图片模型、绑定双渠道、设置默认、编辑优先级、保存后刷新保持配置。
- 1024x1024 参数按优先级列出两条线路；1536x1024 只列出支持该参数的备用线路，并解释主线路排除原因。
- 从画布提交生成，异步 Worker 完成入库，任务中心显示逻辑模型名与实际备用渠道调用记录。预估与最终内部积分均为 4。
- mock 固定返回 640x360 测试图；界面正确提示其与请求尺寸不符，不据此宣称验证了真实模型画幅能力。
- 390px 宽度下页面无横向溢出，编辑弹窗可滚动并保存；Shift+Tab 在弹窗内循环，Esc 可关闭未修改弹窗。
- 图片切换到视频会清理图片参数，模型列表不再混入图片模型；切回图片恢复默认图片模型。
- 浏览器未记录页面脚本错误，修复后的前端生产构建通过。

实际操作发现并修复了画布新节点固定选择 mock、节点卡片显示内部模型编号两处遗漏。新建和拖线创建使用对应类型默认模型，继承已有生成节点时仍保留原选择。证据截图位于开发环境 `.runtime/model-ui-validation/routing-check.png`，不提交测试媒体和数据库数据。

# 创作体验改造执行计划

依据 2026-10-13 讨论：业务对象与工具独立于 Agent；先打通体验和接口，检索质量与 Agent 内核增强后续进行。沿用 main 工作区，不自动提交或推送。

## 顺序与验收

1. [x] 工作台连续对话、多对话：系统持久化消息；新建、切换、重命名、归档、恢复；会话隔离；任务结果回到发起对话；刷新不丢失；后端执行适配独立。
2. [x] 素材入口与使用路径：统一找内容、预览和用途；角色关联片段；标注融入详情；回收站范围统一；返回当前创作。
3. [x] 创作归属与已采用状态：对话不等于作品；候选结果与已采用版本分开，避免隐式覆盖。
4. [x] 任务与修改反馈：统一状态、保存结果、失败恢复、修改记录和适用范围。
5. [x] 高频页面 UI：保留已认可的项目引导区域；改善结果卡、素材列表、编辑正文与剪辑首步。
6. [ ] 端到端验收：真实小作品主流程和中断、重试、切换对话路径；真实模型调用按配置与授权执行，模拟结果明确标识。

后续：检索召回与排序质量、长流程 Agent 规划与多 Agent 协作、更多模型和桌面端。

## 第 1 项实现边界

对话、消息、任务状态与上下文由应用保存；现有 Agent 仅是第一个执行适配器。每段对话独立历史，同一对话默认一次执行，避免输出顺序和修改冲突；不同对话可分别发起任务。已有生成入口与历史记录保留。现有 Agent 的修改审阅机制继续有效，不扩大工具权限。

## 已落地

- **生成工作区**：创作输入、参数、参考和结果分区；宽屏双栏、窄屏纵向。放大结果卡片，增加图片/视频/声音/收藏筛选、指令复用和图片作为参考入口，保留版本比较、钦定、原片来源和原有编辑工具。
- **指令草稿**：按账号、项目、对象保存在当前浏览器，刷新和镜头切换可恢复。复用旧版本指令前，已有非空草稿会要求确认；取消不覆盖。存储失败显示提示。本机草稿不等于跨设备同步。
- **镜头切换**：生成面板默认宽布局，上一镜/下一镜保持当前页签及各自草稿；保留已有用户宽窄偏好。
- **请求边界**：提交中锁定生成输入，参数变化后不显示旧估算；版本加载失败可重试，筛选无结果与尚未生成分开。切换镜头后到达的生成响应仍记录在原镜头任务入口。
- **画布分支复制**：按钮及 Ctrl/Cmd+D 复制选中节点，复制分组时包括子节点，保留输入连线和固定素材/目标引用，生成新的节点与连线身份。运行结果不复制，不发起生成；可撤销、重做、保存和刷新恢复。超过500节点或1500连线时先拒绝复制。
- **画布工作区**：属性面板收起/展开、节点与连线计数、快捷键提示和移动工具栏；节点表面、侧栏与工具栏层次统一。修复 React Flow 内部浅色主题覆盖全站暗色主题的问题。

参考方向延续用户提供的影策首页：中性深色表面、内容优先、主要操作集中、参数与结果分区。本轮使用现有业务与组件实现，未复制影策实现代码。

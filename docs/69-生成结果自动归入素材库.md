# 生成结果自动归入素材库

2026-09-28，主工作区实现，尚未提交。

## 使用方式

- 素材导航新增「AI 生成」，工作台最近创作也提供直达入口。
- 图片、视频任务成功保存结果后，自动显示在该项目的生成素材集合中。历史结果同样可见，无需手动补入。
- 支持类型筛选、提示词或模型 ID 搜索、分页、完整提示词查看、来源任务、预览和下载。
- 图片可用作工作台参考，保持同一生成记录的来源关联；图片和视频均可复用完整提示词。复用提示词不自动提交任务或切换供应商。

## 数据约定

该集合直接索引已有 `Generation`、成功的 `GenerationJob` 与 `Blob`，不再复制生成文件或创建第二份上传记录。这使生成结果和素材显示天然保持一致，也避免后补入库失败、重试重复收录、额外存储开销。

只查询当前项目的图片和视频成功结果；上传和本地处理记录不归入 AI 生成分类。旧的离线测试结果仍保留，文件本身缺失时沿用不可用提示。

生成记录及文件保留现有引用关系与权限。来源对象已移除时仍能查阅生成结果和复用提示词，但不提供工作台图片参考入口，遵守现有参考验证规则。「视频原片」的上传、片段截取和回收站流程保持原有数据模型。

接口：`GET /projects/{id}/library/generated`，以及 `/generated/{generation_id}`。返回的溯源元数据按字段选择，不包含服务密钥或完整供应商配置。

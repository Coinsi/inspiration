# 技能包、创作调用与项目偏好

日期：2026-09-17。承接文档50的第二至第四阶段。用户要求连续补功能，无需逐项请求验收；保持不提交、不合并、不推送。声音创作、付费模型实接和存储运维扩展仍暂缓。

## 已实现

- 技能目录：服务端搜索名称/用途/正文、五类分类、更新时间/名称排序、24项分页、本项目/我创建的跨项目技能/个人收藏。收藏保存在服务器，跨项目列表仅包含当前账号仍有权访问的未删除项目。
- 技能包：SKILL.md入口、最多40个参考/附件文件；MD/TXT/ZIP导入先预览，再编辑保存；识别YAML名称、描述和分类。ZIP不解压到文件系统，校验路径、重复名、链接、加密、条目数和解压后大小。压缩包32MB、单文件1MB、附件总量4MB，入口20000字。
- 详情：文件列表、Markdown阅读/源码切换、表格/列表/代码块、包内文本链接跳转、逐文件下载、ZIP导出；正文和附件一起进入版本历史，历史内容可查看及恢复。二进制附件保存和下载；不自动执行包内脚本，不加载Markdown中的外部图片。
- 来源管理：公开GitHub仓库/目录导入，解析分支到提交SHA，保留仓库/分支/目录/提交。检查更新只填入草稿，核对后才保存新版本；已有工具依赖与分类保留。分支名含斜线时建议使用仓库根地址并单独填写分支与目录。
- 跨项目复用：通过源项目成员权限和来源版本检查，复制为当前项目独立技能包；保留来源技能编号及来源版本，后续编辑互不影响。
- 创作调用：生成面板、画布节点、对象助理共用可搜索的技能选择器，最多4项；Agent沿用最多3项并增加显式版本选择。创建任务时使用不可变版本；生成请求自动带入入口正文中提及的相关文本参考文件，跳过scripts/、assets/，上下文上限32000字，超限明确拒绝。
- Agent按需读取：skill.load返回入口和文件目录；skill.read_file读取该任务固定版本的文本，支持分段读取。工具权限与原有修改审阅不变。
- 追溯：生成任务/产物记录技能编号、名称、版本与实际引用文件SHA256；任务详情展示。画布批次固定技能全文和项目要求，后续编辑/归档不改变已经发起的批次。历史作品复用带回原始指令和技能选择，避免重复追加上下文。
- 设置：新增项目共享的创作偏好，保存默认资产/镜头候选数量、默认参考图开关、图片/视频项目要求、对象助理改稿偏好。管理员修改，成员可读，独立版本号防止覆盖他人修改，本机草稿可刷新恢复，失败保留输入。保留其他Project.settings内容。
- 默认模型：首次进入生成面板且本机未选择模型时，使用启用的默认图片模型；手动选择优先，默认模型仍在既有渠道模型界面管理。视频单结果限制仍以模型能力为准。

## 边界

当前是项目权限内的技能包与跨项目个人复用，没有公开社区市场、任意脚本运行、私有GitHub凭据托管。导演台仍负责机位和参考制作，生成通过既有镜头创作面板承接；未虚设独立生成接口。个人存储配置、平台管理和云模型实接继续按既定TODO处理。

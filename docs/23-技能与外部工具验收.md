## 已实现

- 项目技能支持模板、Markdown文本导入、来源、依赖工具、归档、乐观并发保存和不可变版本历史。恢复旧版本创建新版本。
- Agent启动时固定最多3个所选技能版本。模型通过`skill.load`按需加载，后续修改或归档不改变正在运行的任务。技能文字不提供额外权限。
- 外部MCP客户端通过可选stdio桥接复用项目工具目录与权限。写入请求只创建网页审阅任务；审批时重新检查范围、版本、锁定状态与权限，批准后记录实际变更。外部任务不触发额外文本模型循环。
- JSON外部目录先预览，再导入最多100项资产信息，保留来源标识、链接和资产版本。整批校验、请求编号与内容指纹防止重试重复创建。

## 边界

目录导入只创建资产信息，不下载远程原片、不代表已连接Eagle等账号。MCP为客户端启动的stdio桥接；尚未提供公开HTTP MCP、OAuth发现和自动令牌续期。网页创作助理不要求用户启动此桥接。技能不运行脚本，不扩展任意文件或命令执行能力。

后续继续完善连接配置体验、外部来源只读检索适配和运行诊断；不能把以上边界写成已交付能力。

# 账号模型服务与生成验证

2026-09-28。本轮在 `C:/Code/Python/inspiration` 的 `main` 工作目录直接实现，未提交。

## 使用流程

- 右上角个人设置 → 模型服务，或工作台模型选择器 → 连接或管理模型服务。
- 个人服务配置一次，当前账号在所有已加入的项目均可选择，不复制到项目成员的账号。
- 方舟和 MiniMax 使用官方预置地址，选择模型时不用重新填写 Key。留空保留密钥；更换密钥清除旧验证状态。
- 工作台支持复用已有项目服务到个人账号，包括原有文字、图片、视频渠道。复用不覆盖已有个人密钥，原项目服务保留。
- 项目设置保留项目默认、项目专用服务和高级路由；个人与项目来源在工作台中区分显示。
- 方舟目录补充 Seedream 5.0 Lite、4.0、Seedance 2.0；保留 Seedream 4.5、Seedance 1.5 Pro。目录与可选参数不表示账号已开通所有型号，也不代表高级多模态能力已全部接入。

## 验证状态

保存配置不会调用付费模型。“已验证生成”仅在真实生成任务完成、结果入库后写入。失败显示具体原因；新 Key 重置验证状态。其他成员不能列出个人模型、读取能力、提交或重试使用他人 Key 的任务；使用个人文字模型的 Agent 任务也限制原提交者操作。

个人视频任务记录上游任务 ID。查询失败后重试查询原任务，不重复提交。提交状态不确定时禁止自动重发。配置版本改变后不把旧任务静默切换到新配置。
